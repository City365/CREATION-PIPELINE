接口与参数
除 /health 外，以下接口均需 Bearer 密钥
方法接口用途
POST/api/tasks新建视频任务，返回任务 ID 与状态
GET/api/tasks/{id}查询进度、参数、错误和结果
GET/api/tasks/{id}/file下载已完成任务的 MP4
POST/api/tasks/{id}/cancel停止本地操作，已提交的平台生成无法撤回
POST/api/tasks/{id}/resume续查失败或中断的已提交会话
GET/api/state读取账号、任务与忙碌状态
POST/api/references上传参考图，传入 name、base64，返回 path
prompt 必填提示词；platform doubao / dola；accountId 可选，不填自动分配。
duration 4 / 5 / 10 / 15 / 30 秒；ratio 例如 16:9；model 模型名称。留空沿用网页设置。
references 上传后返回的绝对路径数组，最多 9 张；removeWatermark 请求官方无水印文件；requestId 请求去重标识。
