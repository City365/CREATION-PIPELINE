# 空间、布局与摄像机规则

## 统一坐标
单位米。俯视图西南角为原点 (0,0,0)，+x 向东，+y 向北，+z 向上。北是场景内部约定，未给出地理朝向时不要声称真实朝北。矩形场景宽 W、深 D、层高 H，边界 x∈[0,W]、y∈[0,D]、z∈[0,H]。南墙 y=0、北墙 y=D、西墙 x=0、东墙 x=W。

默认将未指定观察者的“左/右/前/后”解释为从南向北看的西/东/北/南，在补全说明中注明；描述给出观察者时先转换为世界方位。家具自身的前后由其朝向定义，不能直接当房间南北。

非矩形空间用包含它的矩形作坐标框，另列真实边界顶点、凹口和不可用区；不把明确的 L 形或院落改成矩形房间。室外空间列地面标高与构筑物高度，层高写“不适用”，不自动加四面墙。

## 对象模型
地面物体使用中心 (cx,cy)、底部标高 z0、尺寸（局部宽 w、局部深 d、高 h）、朝向 θ。θ=0° 时局部宽轴平行 +x、正面朝 +y；θ 从 +y 向 -x 逆时针增加，90°朝西、180°朝南、270°朝东。正面不适用的物体列长轴方向。

轴对齐物体直接列真实 x/y 范围。旋转物体由局部四角 (±w/2,±d/2) 旋转 θ 再平移得到占地多边形；包围盒仅作快速筛查，不能当真实占地。所有椅子也有占地尺寸，不能仅用点位检查碰撞。

墙面物体与开口列所属墙、沿墙区间、底高/顶高、厚度或向室内突出量。南北墙用 x 区间，东西墙用 y 区间。门列净宽、高、铰链侧、开启方向及扫掠区域；无依据默认关闭展示，但仍预留开启空间。窗列窗台高和窗顶高。桌上物体列承载物 ID 与相对位置，接触允许不算碰撞。

## 合理布局
先安排必须存在的主体和出入口，再安排支撑家具、窗和照明。门窗不可与同墙固定物重叠，家具不堵门，不穿墙，不阻断主要动线；常规主要通路以约 0.8–1.0 米为设计目标，椅后拉出/使用空间约 0.6–0.9 米，根据用途调整。这些是概念布局参考，不宣称满足建筑法规。

尺寸补全采用常见人体尺度并检查组合后的可用性，不机械套默认尺寸。例如会议桌、座椅与椅后通路必须一起放得下；空间未给定时可扩大推定空间，空间已给定时优先调整推定家具。床边留通路、柜门留操作空间、座位朝向功能对象。风格缺失采用克制写实，保留场景时代线索；不要给古代房间补投影幕或现代筒灯。

明确项优先于推定项；布局需要补的建筑构件与少量功能家具都标记推定。不要凭空增加人物、故事线索或密集装饰。

## 固定摄像机
室内机位距墙内侧 ε，默认 ε=0.15 米；过小空间按比例减小。水平视图高度默认 1.6 米，不适合时按空间调整并注明。摄像机应处于自由空间，不嵌入柜子、墙或门板。沿对应墙微移可避障，报告实际坐标与目标点；不要移动家具让机位成立。

- 正视：位置 (W/2,ε,1.6)，目标 (W/2,D/2,1.6)，朝 +y。画面左=西、右=东，远端=北。
- 反视：位置 (W/2,D-ε,1.6)，目标 (W/2,D/2,1.6)，朝 -y。画面左=东、右=西，远端=南。
- 侧视：位置 (ε,D/2,1.6)，目标 (W/2,D/2,1.6)，朝 +x。画面左=北、右=南，远端=东。
- 俯视：位置 (W/2,D/2,Zcam)，垂直朝 -z，画面上方=北，右方=东；Zcam 高于最高结构，正交取景覆盖真实边界并留少量边距。标注去顶展示。

前述左右映射用于正对坐标轴的机位；若目标点改变形成斜视，要根据实际方向重新计算，不能照抄映射。默认水平画角约 70°，可根据宽深比例调整，避免极端广角；报告实际画角，俯视报告正交覆盖范围。机位只保证合理取景，不保证每件物品均可见。

灯、窗光方向固定在世界坐标，反视不能把光源换墙。靠近机位的门窗可能在画面外；描述其真实位置，并明确不可见或画外，不能硬塞进画面。
