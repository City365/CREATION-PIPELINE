# 打斗与身体交手

只有当前画面真有交手才进入本分支。逐条检查动作前态→起动→接触或未接触→对手已有反应→结束落点。细化支撑、重心和路径只为拍清原动作，不新增招式、能力、伤势、胜负或终结结果。没有写命中就不能写成命中；有武器才用武器，不把尘土/冲击波变成新能力。

## 逐条执行检查

按已有动作列起点姿态、接触双方、移动方向、目标、实际接触与反应、结束支撑及持物。先写动作因果，再落实镜头和原文已有特效。

- 一个源条目内只有一次明确攻击时，围绕它组织起动、接触/避开和落点，不加一串连招。
- 同轴或侧向中景可用于看清双方距离、路径和接触；局部特写仅在关系已清楚时强调现有接触。运动速度不能使命中与受力对象不可辨。
- 武器、支撑手脚、身体重心前后连续；武器不穿模、不无交接换手；手里有道具不能同时空手抓握。
- 原文写格挡就保留格挡结果，不自动升级反杀；原文只写突进不自动写命中。撞倒、飞出、受伤均需当前输入依据。
- 结束位置与下一条起点一致；留足既有反应和落地时间，声画装不下就报告冲突。

例：输入一条2秒画面“甲挥拳，乙侧身避开，双方仍站立”。只输出一个Shot，选择可见两人的侧向中景，在同条写挥拳路径与乙避开，末态仍站立；不得写击中、鲜血、追加踢击或扩成3个Shot。

这是有限的通用转换分支。尚没有可证明覆盖各种复杂招式的生成实测，不宣称打斗效果已通过验收。
