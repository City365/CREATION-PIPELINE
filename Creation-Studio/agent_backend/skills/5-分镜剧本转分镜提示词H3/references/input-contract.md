# 输入变量与素材权限

一、识别输入
- {{输入文案}}：当前这一组待转换的剧本，是当前对白、事件、动作、声道和截止状态的任务来源。
- {{推文文案}}：整集或整篇内容，仅用于理解背景、判断上下文及定位当前段；不能把后文事件提前演入本组。
- {{故事情节}}、{{章节情节}}：作品或章节背景，不能据此补对白、改结果。
- {{角色信息}}、{{场景信息}}、{{物品信息}}：名称、别名和描述，用于实体映射、外观、材质、空间和可见细节。
- 前序分镜或上组末态：仅在实际传入时使用，作为已发生状态参考；不声称能读取未传入的历史会话或数据库。
- 声音设定或音色卡（可选，本版扩展接口）：显式传入的音色描述、声音ID或声样参考；没提供不等于已有默认音色。
- 当前提示词JSON：text通常是当前文案镜像；prompt、video_prompt只有实际含值时才是已有提示词参考，空字符串不构成资料。
- {{小说原文}}：不是默认分镜推理材料；除非用户另行要求提炼，不从中抽取本组新对白或情节。

二、确定当前处理对象
明确提供{{输入文案}}时，以它为本次转换对象。JSON.text与它相同只处理一次；不同也不拼接，两份不能互相补剧情。仅当未提供独立当前文案、调用方明确以JSON.text作为当前输入时，才读取JSON.text。没有可识别的当前输入则给出缺失项，不猜哪一组。

前序参考负责说明此前已发生状态；当前明确动作负责更新状态。实体资料负责身份与视觉设定；本组背景、画面和台词负责当前事件。相同层级的关键事实互相矛盾时，不通过导演设计偷偷改掉其中一项。

三、锁定逐条源清单
按Ⅰ、Ⅱ、Ⅲ等输入编号建立一一映射，记录每条时长、画面事件、快切节拍、对白原文、说话人、声道、开始状态和结束限制。重新计算对白字数，不盲信括号中的字数标注。

禁止把“背景里提到”“角色库里有”“后文将发生”当成本组实际出镜或发生的充分依据。当前组只要求林辰转头时，不提前表现后文的落泪、拥抱或新一段OS。


输入台词默认不变；过载例外与审计见[timing-and-overload.md](timing-and-overload.md)。当前没有提供资产库时使用text-only，不制造@引用。
