# 横屏空间、前序与动态状态

一、分开维护三类信息
物理场景：门、讲台、桌椅、窗、通道和人物所在区域的相对关系，以及光源和场景时间。
人物与道具动态：位置、站/坐、姿态、朝向、视线、哪只手持什么、接触是否发生、动作进行到哪一步。
摄影关系：相机在哪里、朝哪里拍、哪些人在前中后景和屏幕哪边、焦点与遮挡。

二、起点建立
实际给了前序，就从其已确认末态接入。首组没有前序时，前序留空，依据当前输入及场景资料建立起点，不虚构上一场。
新场景空间建立需要可辨的固定参照与关系轴线，条件允许时用三个已存在参照物。若锁定首条是局部特写，不强加全景、不虚构参照物；可在同条既有宽构图或后续原有关系画面中自然交代，工作记录注明覆盖限制。这是本版为避免空间建议改动锁定分镜而作的本地协调，不是新增服务器证据。
已有入场动作时，借该动作确立初始站位；原文直接开始交谈时，不为套“入场”规则让人物重新走进来。

三、更新条件
每条从前一条结束状态开始；有明确动作才更新相应状态。角色转头只更新头部/视线，不能自动升级为转身、走近、拥抱或哭泣。台词中的命令、愿望、计划与执行结果分开：“起立”不等于已经站起，“我要走了”不等于已经出门。
道具必须有可追踪状态：谁持有、哪只手、是否交接、放在哪里。未接触不写成抓住，未交付不写成已拿到。微动作也要满足手部占用和身体重心。

四、轴线与画面坐标
同场景对话保持关系轴线清楚；反打在已建立关系内组织视线。相机换位后，重新描述实际屏幕位置，不机械冻结所有镜头的左右，也不把“画面左”当永久世界坐标。
人物物理位置未移动时，不通过换机位的文字把其写到场景另一处。主光源在同一物理窗侧，切机位后仍是同一个光源；它在画面中的方位需要结合相机方向描述。
需要跨轴或重新建立关系时，在该条已有快切范围内用清楚的中性机位、关系构图或可见移动交代；不为解决摄影问题添加角色转身等剧情动作。

五、末态闭合
END FRAME / END BEAT交代最后可确认的位置、姿态、朝向/视线、持物与接触结果，必要时补光线和焦点落点。不写本组尚未发生的下一步，不让末态比动作正文前进一拍。
未给全的前序只继承能确认的部分；新选的角落坐标不能冒称前组已经确认。无需表现的背景人物精确位置可以保持未锁定。


# 场景时间与光线

每个当前场景确定：场景标准名、内外、叙事时间、主要空间参照、物理主光来源、光质、明暗关系与材质反馈。

时间首先服从当前原文；未写清的日期、季节、年代不自行补成剧情设定。日景不自动改夕阳，夜景不自动加暴雨，镜头推进不代表时间跳转。
场景资料已经给出的墙地材质、门窗/通道与布置沿用；普通成像所需但未给出的光向或构图可以设计，但不得改变事件条件。

同场景连续段落沿用已选主光来源与时间。主体换向后，受光面可以随物理关系改变，不能为了每次面部好看就无故把主光换到另一侧。只写有意义的软硬、明暗和色温倾向，不在没有依据时把精确K值或镜头焦距写成资料事实。

新场景重新建立本场锚点与光照；不把上一场屏幕左右和窗光机械搬过去。输入明确多场景时按原顺序呈现，不删场景来迁就“一个主场景”的概括；具体跨场编排见特殊条目模块。

全组光照总述与各条LOCATION、动作受光保持同一物理主光来源。不能在没有来源变化时更换窗侧或灯位；相机换向后，光源的屏幕方位可以改变，应结合机位重新描述，不能仅凭左右字面变化判断换光。不要将同一时刻写成day和night。


## 多组调用约定

调用方须把已确认末态实际传给下一组。本包不提供隐藏数据库或自动记忆。每次继承按实体标准名对齐，不按组内Subject编号；记录相同人物的姿势、物理区域、朝向、手部占用、道具去向和声音资料来源。另存上一机位及屏幕位置，换机位时重新计算可见关系。

本次导演设计一旦选定且动作没有改变，可作为后组连续性参考；仍保留design来源，不改成原文事实。新场景清空旧场空间坐标，只继承实际跨场携带的人物/道具与已给身份资料。未发生的命令、计划不写入已完成状态。
