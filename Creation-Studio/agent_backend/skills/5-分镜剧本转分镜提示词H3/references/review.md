# 终审


1. 当前组截止正确，没有从全文、示例或实体库追加后续剧情。
2. 输入N条画面恰好输出N个[Shot]，逐条映射，无子编号、扩号、合号或重排。
3. 未压缩句相对原稿逐字一致；压缩句相对授权执行稿逐字一致，并另通过原句→新句的核心语义审计。出现次数、说话人、顺序和OS/现场属性不变，无重复抄写的声轨。
4. 原条时长与组总时长一致，累计时标正确；预算可成立时才称完成，未实测不称实测。
5. 所有@引用能在输入库中找到，组内ID一致；人物/道具不交换，未把只闻其声标成可见。
6. 每条有九字段；相机描述与人物可见部分相容，焦点路径的次数与起止一致。
7. 物理空间、关系轴线、主光源与人物/道具状态连续；动作正文和末态无跳步。
8. 重要对白清楚，OS与现场画外声不混；同Shot多条原声均保留，切画不重播。已有音色身份沿用，未给资料不冒称继承；无配乐、无字幕设计。
9. summary和retention_analysis反映实际镜头，不为证明保留而编造新镜头。
10. 正常成品封装首尾准确，没有诊断注入、未替换占位符或示例泄漏。
发现普通导演实现问题直接修正；涉及改变锁定输入的不可解冲突才走异常出口。


## 两层忠实与估算范围

无压缩：用原稿检查成品台词。有压缩：先用check-edits核对原稿→执行稿，再用check-output核对执行稿→成品，不能省略前一步。check-edits中的semanticReview只是显式审阅结论，脚本不理解情节；关键事实及删除项还需逐项看。

check-timing检查选定参数下的预算、声窗边界与同一人物重叠；输入错误读法、遗漏停顿、过早发声等仍可能使实际失败。静态通过不代表发音准确、医学正确、空间成立、导入兼容或视频好看。

脚本目前仅支持中文分镜的标准画面行和台词行。check-output每次一组；多组先保持组边界分开核对，不把整个汇总文件当单组。check-edits要求原稿和执行稿除登记台词外完全一致；先在同一份规范化原稿上编辑，不给原稿另行排版。

文件比较允许LF/CRLF换行归一化，其他非台词正文保持原样。若说话人使用别名，传入assets中name/aliases映射；无可解析映射时检查器会报说话人不匹配，不静默放过。
