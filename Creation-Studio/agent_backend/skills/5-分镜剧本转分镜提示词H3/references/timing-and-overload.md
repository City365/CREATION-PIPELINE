# 声画计时与过载压缩

四、语速与预算
预估发声时长 = 句首起音 + 实际中文发声字数÷语速 + 标点停顿 + 情绪停顿 + 重点强调停顿 + 句尾收尾。
计数排除说话人、声道、制作说明和标点；数字、英文、金额按实际读法展开，读法未定时标记预算不确定，不把字符数冒充读音时长。

语速：
极快5.5–6字/秒用于短促抢话或打断；特别焦急的短时通报和抢救呼喊，按用户新规则允许6—6.5字/秒，包括必须保留的核心信息，但数字与术语必须清楚。不得将该档扩展为所有场面的默认速度。
偏快4.5–5字/秒，用于愤怒、质问或急切解释。
正常4–4.5字/秒，用于普通对话。
正常偏慢3.5–4字/秒，用于揭穿、算账、威胁或证据说明。
慢3–3.5字/秒，用于悲伤、哽咽、临界承诺或强情绪阻拦。
极慢2–2.5字/秒，仅短句爆点。

停顿：逗号/顿号0.2–0.4秒；句号/问号/感叹号0.4–0.8秒；省略号0.8–1.5秒；数字/金额补0.3–0.6秒；地名/书名/证据补0.4–0.8秒；威胁/承诺补0.5–1秒；情绪爆点前后补0.3–0.8秒。
起音：普通0.1秒，哭喊/怒吼等爆点0.2秒。收尾：普通0.1秒，余韵/哽咽/叹息0.2–0.3秒。
同一实际停顿不因多个解释标签重复累计；确实依次发生的停顿分别计入。区间是预算，只有实际音频才是实测时长。

情绪与语速匹配，核心信息清楚；急切阻拦不能无因拖慢，崩溃哭喊不能标成平静，冷静揭穿或证据信息不能靠极快含糊塞完。

五、声画占时
同一人顺序说话累加；同时说话可并行但需实际同时成立。走路与讲话可并行，但不得把必须依次发生的动作都当并行；切画不代表对白重启，反应时间不能被重复占用。
先检查预算，再做繁复摄影。不得新增编号、未经授权改词、擅自拉长时长或突破6.5字/秒伪装通过。过载时先执行已授权的等义压缩及复核；核心信息不可再压而仍不容纳时，才按异常出口列出条目、计数、参数和冲突，不能称成品已通过。

六、视频时标
组时长沿用输入；每条DURATION沿用其对应时长。条目开始时间为前面各条时长累计，不按0.5秒强行量化。
[Shot N] At MM:SS.mmm中的时标是当前组视频时间；TIME MARKER说明叙事上的连续/时间跳跃，二者不能混为一谈。秒位保持两位，不写00:011.000之类格式。


## 真实过载才允许等义压缩

来源：用户本轮明确要求。优先于v0.4.1“任何情况下逐字不改”的旧绝对表述；没有追加API请求，也不是声称服务器原模板已有该规则。

1. 默认原词保留。只有在当前条目的真实可用声窗中，原句按符合场面的语速、读数及停顿仍过载，才启用压缩；不能为了文风、短句偏好或省事改词。
2. 先把声轨与画面合理并行：条内切画不重播原句，现场声/OS可跨条内切点。再按情境选择语速；特别焦急的通报、抢救呼喊可6—6.5字/秒，不扩为所有日常/证据/悲伤段落的默认值。
3. 仍过载时提取本场核心信息，再压称呼、套话、重复修饰和可理解的同义结构。不得改说话人、声道、事件次序、否定/条件、关键数值单位、左右侧、病情状态、行动目标或结果。
4. 用户给了核心取舍示例时按该口径处理：本次护士句重点为事故和患者状态，允许两分钟概括为即将、删调度套话和次要修饰。不能据此在其他情节普遍删除关键倒计时、性别线索或伤情程度。
5. 每条改写记录触发预算、原句、新句、核心信息对应和删除项；原句不被覆盖。改写后重算预算并做语义核对；数字读法明确，不把字数估计当实测。
6. 原画面编号、分组、总时长、视觉结果和道具线索保持；压台词不能删旧伤、打火机刻字等视觉信息，也不能新增剧情。
7. 新句仍不容纳时才报告最小冲突，不无限删到丢核心，不突破6.5字/秒伪装通过。正常成品按已核对的新句登记；原词检查须对“授权执行稿”检查，并另保原句→新句审计，不能冒称相对最初原稿逐字一致。

## 台账与复核

1. 每个原声单元确定所属组、源Shot、说话人/声道、实际读法、语速、起音、收尾、逐个停顿及真实声窗。不要将全文字数标注当读数。
2. 一个声窗是本条内允许发声的区间；同一人先后说话累加，动作可并行的才并行。多人物同时说话需要输入或表演依据，不能用并发掩盖信息不可听清。
3. 同一实际停顿只登记一个id，多重作用写在reason中；不按多个标签重复累加，也不能把两个实际停顿合并偷减。数字/英文读音未确定时标未知，不能报预算通过。
4. 过载前的预算必须采用已尝试的合理声窗和情境允许语速，不能故意选过窄声窗或过慢语速制造改词资格。记录调整及其理由。
5. 编辑台账逐条写原句、新句、原读法、过载前预算参数、触发理由、保留事实、删除/概括项、保护词和语义审阅。用户的特定取舍只对其指定案例有效。
6. 改写后重新计时。改词但没有原稿/执行稿/台账不能声称审核通过。语义审阅是单独判断，结构脚本不能替代。
7. 极紧预算仍标注风险；未有音频时只有选定参数的估算，不能声称实际发声准确或可懂度已通过。读音有歧义（如70/40）必须在配音时清楚分组并实测。

模板：[计时台账](../assets/timing-ledger.json)、[改写台账](../assets/rewrite-ledger.json)；schemaVersion为0.4.2。计时每项含group、shot、voiceIndex、speaker、channel、text、spokenText、shotDuration、windowStart、windowEnd、start、rate、onset、tail、pauses。pauses为{id,seconds,reason}数组；urgentSpeech和urgentReason说明6—6.5档例外。语义、读数与停顿参数仍需审阅。
