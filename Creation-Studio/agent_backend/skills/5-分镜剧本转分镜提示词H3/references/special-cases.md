# 特殊条目与异常出口

本节是为使v0.4.1可执行而补充的暂行处理，尚未由小行星服务器逐项验证。遇到这些情况不把暂行办法说成平台原规则。

零秒条目：先判断是不是前一持续画面的状态说明。仍保留输入编号对应关系，DURATION写0s，开始时标与当时累计值相同；只登记已有末态，不新增动作、对白、运镜或额外占时。若零秒条目要求独立发生的新动作或新对白，作为时长冲突处理。目标软件是否支持零秒导入须另行验证。

多场景：只采用当前输入已经提供的场景及转移顺序。在原编号条目内按阶段写清地点变化，定义实际所需Scene，不另编一组或删除场景。新场景重建空间/光线，不把上一场坐标继承为新场位置。跨地点的快切可表达原文已明确的省略，但不据此发明路程、耗时或中途事件。

打斗/身体交手：按需读取[fight.md](fight.md)，保持源编号及原文攻防结果。

缺少实体：先用已给别名映射；仍找不到则用原名普通文本，不伪造@资产。若缺失使人物身份无法区分，列出具体缺口；不擅自将两个人合成一个。

关键矛盾或不可容纳：若合理声画并行、情境允许的语速及已授权等义压缩都不能使编号、核心语义、锁定时长与事件前提同时满足，不输出貌似已经通过的正常成品；给一份简短“输入需修复”记录，包含具体条目、冲突原句或计算、最小修改方案以及需要改动的锁定项。只需例行摄影选择时不进入该出口，不把普通导演决策变成确认流程。

审核/诊断模式：用户明确要求分析时，只给结论、来源对应、计算和待解决项；不要求或输出隐藏内部思维过程，不将诊断附注写入剧情、台词或正常成品summary。
