# 转换参考案例

以下只教转换方法，不是当前剧情资料。角色、地点、对白、时长和设计值不能泄漏到其他输入。

案例A：资料事实与设计
输入场景给出浅灰水磨石地面，只说自然漫射光均匀；画面没有明确窗位。
处理：地面材质直接采用；需要选择窗光方向时将它视为本次设计，后续保持同一物理来源。不能说“资料明确左窗”，也不能每镜换窗侧。

案例B：命令不是动作结果
原句“起立”，画面只写付尚面对提问，未写起身。
处理：保留命令对白和坐姿；可选择已有情绪下的短反应，但不写“已经站起”。若后一个原画面明确站起，才在那里更新状态。

案例C：两个合理摄影方案
观看任务：楚若楠低头微笑，随后林辰OS确认。
固定过肩移焦：两人均须在同一构图；林辰想被看见的侧脸必须实际可见。焦点从楚若楠到林辰只转移一次。
同轴反打：可在条内既定切点先交代一方，再切另一方；需保持相互视线和空间。
选择：依据本条快切、观看任务与可见性决定，不强行指定所有同类剧情都用移焦。若林辰只有后脑，调整机位或使用成立的反打，不能靠移焦制造正脸或新增转身。

案例D：快切不扩号
输入Ⅰ含“说话人→听者反应→回说话人”，只有这一条编号。
处理：只输出[Shot 1]，在该条字段写明三段观看顺序。台词正文仍只登记一次，切听者时标为同一现场声继续。不是[Shot 1]、[Shot 2]、[Shot 3]，也不是把原快切全删掉。

案例E：心声不改声道
画面中人物表面平静，原句标OS。
处理：原词在Dialogue标OS，画面只给已有反差的可见表演，嘴部无说话同步要求；声音可清晰靠前，但不凭OS新增回忆画面或读心机制。

案例F：结束在正在发生的动作
输入只到林辰转头，限制本组不落泪。
处理：Action写转头过程，END写转头后的视线落点；不写眼泪落下、站起奔向对方或下一段未给的OS。

案例G：编号固定的零秒记录
Ⅰ为3秒持续镜头；Ⅱ为0秒，明确说结尾状态包含在Ⅰ的持续画面中。
本版暂行处理：Ⅰ正常写3秒；Ⅱ保留编号、DURATION为0s、时标仍为00:03.000，只登记相同状态，不新加动作或额外0.5秒。该处理是本版编排，尚无平台导入验证。

案例H：真实冲突
输入5秒却给出无法在允许语速与停顿内说完的完整证据说明。
处理：精确列计数和预算，先按用户已授权的过载等义压缩处理、复核核心语义并重算；不能删掉核心信息、突破6.5字/秒、扩编号或假称通过。若必要信息仍不容纳，再说明冲突及最小调整方案。

完整教学输入输出按需读取本目录并见index.md；本地教学例不是新增API证据，服务器映射例另保留原答与适用边界。

案例I：空间/表演/OS的正向字段映射
楚若楠独坐角落→LOCATION/Action/END；低头微笑→Action中的可见反应；林辰确认原句→Dialogue标OS，跨切点延续→Action/SOUND。精确屏幕位置属于设计。完整的服务器原答与当前输入放在server09-mapping.md；这是字段路由案例，原4秒条目的OS覆盖窗仍需预算检查，不能当作时间执行已通过。

案例J：同Shot多条原声与条内切画
同一源画面有教师现场一句、学生现场一句、学生OS一句，全部在对应一个Shot的Dialogue登记；OS开始后切到老师反应，学生嘴型不可配OS，声音继续但不复制原句。multi-voice-output.txt是本地教学写法，不是新增API返回。

案例K：固定音色没有提供
本次只有外观资料和前组姿势，不宣称已有固定音色。可以写当前说话情绪和现场/OS处理；固定身份参数在工作记录保持未知。另行提供音色卡后才按标准名绑定，切画与改语气不重置该身份。
