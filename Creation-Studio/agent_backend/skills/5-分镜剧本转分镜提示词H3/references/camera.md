# 观看任务、景别与运镜取舍

先明确这条画面要让观众知道什么，再选择能实际传达信息的摄影方案。不能因为想用环绕、急推或移焦，就为人物增加转身、移动或新反应。

一、识别观看任务
- 空间建立：让观众知道人物、出入口和行动区域的关系。
- 说话/反应：让观众看清谁在说、谁在听、反应何时发生。
- 关系：让同框或反打交代相互方向和距离。
- 移动：让起点、路径、终点与遮挡关系清楚。
- 揭示：按原文顺序从已知主体引到新看见的信息。
- 细节：让道具、持物、接触或局部反应成为可见信息。

二、按可行条件选方案
先排除看不到目标信息、破坏空间关系、要求新增人物动作、或无法在时长内完成的方案。再从其余方案中选最能服务当前观看任务并保留原快切安排的一种。这里是本版的执行顺序，不声称平台有唯一评分公式。
普通对白可以稳定固定；强信息可用近景或适度推进；关系建立可用双人同框或深景深。不是每条都必须运动，也不是所有情绪都自动用特写。

约束与自由选择分开：
- 必须保留：原事件和观看信息顺序、人物可见性、已建立的物理关系/视线、原声与声道、锁定时长和明确技术限制。
- 可选择：满足这些条件后的景别、成立机位、固定或适度运动、同框或同轴反打、必要焦点调度。没有取得适用于全部场景的唯一评分算法，不为本次选择编出固定排名。
- 原快切可成立时直接保留。替代的是摄影方法，不是删除观看信息；“快切建议”中的切/回在不损失功能与原声时可以用注意转移实现。若输入明确要求实际硬切，必须保留切点；明确禁止移焦，就排除移焦。固定编号并不禁止条内硬切。
- “楚若楠在后景”之类值只约束相应同框设计，不约束所有反打。切到她的近景不代表她在物理场景中换了位置。
- 连续OS是声轨要求，不构成长镜头要求，不以“避免中断OS”为由一律取消切镜。

三、技术类别与适用任务
Fixed / Static：重要对白、复杂站位和需要稳定观察的表演。
Push-in：集中注意力，推进到明确人物或细节。
Fast push-in：原文已有关键揭示或爆点时短促强调；不自造爆点。
Pull-back：从局部揭示已存在的空间关系。
Pan：连接同一空间中方向关系明确的主体。
Tracking：跟随原文明确移动，保持人物与路径关系。
Orbit：原文任务适合身份揭示或强对峙，且环绕路径能成立时使用。
Crane / Pedestal：表达明确上下关系；不为炫技加入无信息升降。
Subtle handheld：近距离冲突需要轻微不稳定感时使用，不让晃动遮蔽信息。
Rack focus：在同一可成立构图中转移前后景清晰主体和叙事注意。
这些名称的英文写法是本版术语规范；用途依据服务器返回类别，不是取得了其目录原文。

四、主运镜、焦点与快切
每个连续摄影段安排一种主要机身运动，写清起点、方向、终点及落点。固定加一次移焦可以成立；焦点调度不能冒充人物移动，也不能同时自称只移焦一次却写A→B→A。
一个编号条目有原定快切时，在相应字段中按first / then / cut within this shot条理描述，并让时间、人物和对白连贯，不输出[Shot N.1]、[Shot N-A]或额外编号。

五、几何与可见性
移焦只能改变清晰范围，不能改变相机所在的一侧，不能穿过身体、遮挡物，不能把后脑变成正面反应。
固定过肩移焦成立的前提：前后景目标均在同一构图里，想看的人物反应确实可见。要看林辰侧脸，就在不改变原人物动作的前提下调整机位取得侧脸/眼尾，不能仅写“移焦后出现正脸”。
同轴反打也可能成立，前提是视线关系清楚且条内切点允许；它与同框移焦不是唯一优劣关系。选择依据是观看任务、既有快切和空间可见性。

六、逐条落笔
每条说明相机的实际位置和拍摄方向、角色屏幕左右与前中后景、所选景别、主要运动、焦点及结束构图。避免“正面机位/背后机位”同时指同一相机；避免后脑构图又描写眼神正面细节。
