# 对白、音色、声场与时长预算

一、原声保真与过载例外

过载例外流程：先核对原句在本条真实声窗的发声预算，不能只按文字长短猜测。原声与画面可在同一源条目内合理并行；特别焦急的通报/抢救呼喊允许6—6.5字/秒，但非紧急场面不使用此档。仍超载时，只压掉不影响本场核心的称呼、套话、冗余修饰，或用明确同义结构；不得改说话人、声道、关键数值单位、左右侧、病情性质/程度、指令对象、事件因果及结果。用户已指定核心取舍时以该口径执行；本次护士例允许概括到达时间与事故细节，不能推广为所有场景都能删倒计时或伤情线索。每次压缩记原句、新句、触发预算和核心对应；不触发时不改。压缩后重新计数、计算及核对，仍过载才走异常出口。
未触发过载例外时，每句正文逐字保持原输入，包括标点、重复、未完句和引用。触发例外时，保留原句记录与授权执行句，先核对事件、对象、状态、数值/单位、侧别、否定及结果，再按执行句生成。原文重复说的话要按原次数保留；不能因为两句话相似就去重。对白唯一来源是当前输入，实体库、全文、示例和制作附注均不提供新台词。

Dialogue中用说话人标准实体及声道标注，再放原句或已审核的过载执行句：
@标准名 <Subject N> (onscreen / offscreen diegetic / OS; delivery directions), says:<d>[Chinese]原句或授权执行句</d>
同条中多位说话人分别写，保持原顺序；同时发声标明simultaneous，不按先后重复播放。没有台词写None，不编词。
一个原声单元指当前源条目中的一条台词记录，包括说话人、声道和整句原文；原文相同字句若明确重复出现，是不同的原声单元，应保留原次数。
一个Shot的Dialogue字段可以包含多条不同原声单元，按原顺序逐条写，不能误解为一个Shot只能一句。每个单元只在其对应源编号条目登记一次：未压缩用原句，触发例外用已核对的执行句；不能为了切画把一句拆走到新增编号或其他源条目。
条内切到听者时，现场对白继续在原空间画外延续；切点前后仅标声轨覆盖和延续，不重抄整句或尾句，不重播。OS也不因角色出现在画面中就变成现场对白。

二、稳定声音与当句表演分开
有明确传入的声音设定或前组固定音色资料，才按该人物标准名绑定并沿用。没有时，固定音色资料记为未知，只设计本句有依据的语气、音量、咬字、停顿和声场，不声称已从外观资料继承声音。
本版默认采用上述保守缺失处理；这是依据11本次案例选择的实现，不能宣称原平台所有情况下都不设计音色。用户另行明确要求补建音色卡时，可在工作记录中标为导演设计并通过调用方传给后组，不能伪称原资料明示。
角色性别/年龄的外观描述不等于已经给出具体音区、音质、口音或声音ID；没有固定声音字典或声样时，不自称拿到了平台默认算法。
身份音色包括音区、音质、共鸣、口音等稳定特征；当句参数包括语速、音量、情绪、停顿和重音。愤怒、低声或OS不能使同一个人物变成另一个声线身份。

三、现场与OS
现场对白的空间方向服从人物物理位置，不随切镜任意跳到近景主体身上。反打听者时说话人仍从原现场方向发声。
OS是主观内心声，不随角色是否在画面中改成现场传播，也不要求嘴型同步；有已给声音身份时仍绑定同一人物。连续OS允许画面切到原文已有的主体或反应，声轨不因此中断、重播或改成现场对白。
默认不把现场扩音器/远距离混响套到OS；若输入另有主观声效风格则按明确输入处理，不把“所有OS绝对没有任何混响”写成通用禁令。输入确有心声变模糊、超出范围等声音事件时按原文表现，不自行增加读心能力规则或新台词。
环境声维持场景连续，动作声依实际动作出现；原文只有笑声不自动推出拍桌等独立动作声，不让人声、笑声或拟音盖住重要信息；无原词的背景人声保持不可辨，不新增可听清的句子。禁止配乐与情绪音乐。


有对白时继续读[timing-and-overload.md](timing-and-overload.md)。OS与现场每条均校验，同一个Shot可以有多条不同原声，但每条只登记一次。
