# 版本与依据边界

版本：0.4.2；名称：剧本转分镜·小行星横屏。
基础：独立小行星v0.4 → 服务器09—11整合v0.4.1 → 用户过载规则修订稿 → 本次标准Skill打包。不引用旧小行星v0.1—v0.3为本版依据。

## 四种依据不能互换

- 用户要求：16:9；源画面与Shot严格一一对应；默认原词，仅真实过载等义压缩；特别焦急6—6.5字/秒；不加字幕/音乐。
- 服务器诊断自述：09给出空间、动作、快切、OS到字段的案例映射；10讨论摄影可行条件与替代方案；11讨论声道和缺失音色资料。它们支持有限转换职责，不证明原提示词完整章节结构。
- 历史样例：28组配对提供输出结构和实现参考，多为竖屏历史资料；不能用它们覆盖用户横屏要求，不能证明原始请求上下文或规则原文。
- 本地实现：渐进加载文件组织、状态/计时/编辑台账、字段校验、异常处理与摄影择优顺序。不是服务器原生接口或平台默认算法。

## 本次实际改变

1. 把完整长稿拆成按阶段/条件读取的模块，正文不再载入研究日志。
2. 同步所有模块中的过载例外，保留原稿、执行稿和映射；增加改写及声窗脚本。
3. 协调“首镜三个参照物”与锁定特写的矛盾：优先保留源镜头，不为凑数加场景或全景；空间不足显式记录。此项是本地优化。
4. 使用可移植相对路径；不带密钥、API客户端、付费请求或原始详细思维过程。
5. 静态校验与运行示例不代表新一轮官方API探查、真实语音或视频验收。未宣称恢复官方原模板。

## 仍有限的地方

摄影方案没有已恢复的唯一评分公式；复杂打斗、零秒导入、多场景单条导入、真实配音可懂度仍须测试。身份音色只沿用已提供资料，未知保持未知。跨组继承必须由调用方传入上组末态，不能靠技能名字实现自动持久记忆。

研究原档保留于项目，小行星v0.4.1及既有“剧本转分镜”Skill均不覆盖。本包可独立使用，无需读取项目外部路径。
