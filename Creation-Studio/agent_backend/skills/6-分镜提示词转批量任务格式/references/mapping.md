# 素材匹配配置 mapping.json

`scripts/build_tasks.py` 默认读取本 skill 根目录的 `mapping.json`（`--map` 可指定别的）。
它只影响「文本里的名字」怎么找到「素材库里的文件」，不影响提示词。

```json
{
  "aliases": {
    "赵庭香": "陈淑梅",
    "陈泽健": "陈择健",
    "同班同学们": "同学"
  },
  "scenes": {
    "林辰家屋内外": ["林辰家门口", "林辰家客厅"],
    "旧社区理发店内及门外": ["理发店内", "理发店门口"],
    "教室": ["高三六班教室"]
  },
  "character_pins": {
    "林辰": ["林辰_短发新蓝白校服_四视图_v1.png"]
  }
}
```

## aliases：角色别名

键是文本里出现的名字，值是素材库里的文件名前缀。

- 文本写「赵庭香」，素材叫「陈淑梅」→ 加 `"赵庭香": "陈淑梅"`。
- 文本写「同班同学们」，素材叫「同学」→ 加 `"同班同学们": "同学"`。
- 没配别名的，直接用原名在 `人物/` 里按前缀找。

## scenes：场景映射

键是文本「场景：」里的一个片段（`｜内｜夜` 之后会被截掉），值是素材场景名数组，按顺序挂参考图。

- 一个文本场景对应多个素材场景时写数组，例如理发店「外及店内」→ 门口 + 店内。
- 值是「素材文件名里包含的名字」，不用写编号和版本后缀。
- 没配的场景，脚本先按文件名包含关系找；找不到再按「及 / 和 / 与」拆开逐个找。

新剧/新场景时，照着加几行即可；也可以直接删掉不适用的条目，交给自动匹配。

## character_pins：固定某个角色的图

同一角色有多张图时，脚本默认按文本里的「长发 / 短发 / 杀马特」推断造型；
推断不准就用 pins 固定，值是 `人物/` 下的文件名（或绝对路径）数组。

```json
"character_pins": {
  "林辰": ["林辰_短发新蓝白校服_四视图_v1.png"]
}
```

pins 优先级最高，命中后不再走造型推断。

## 造型推断规则（没有 pins 时）

1. 文本出现「短发」且没有「长发 / 杀马特」→ 选文件名带「短发」的。
2. 文本出现「长发 / 杀马特」且没有「短发」→ 选文件名不带「短发」的。
3. 两种都有（剪发那一镜）→ 长发、短发两张都挂，note 分别标「（长发）」「（短发）」。
4. 都没写 → 继承上一条的状态；第一条默认长发。
5. 仍有多个候选 → 取文件名最短的一张并告警。

## 场景顺序

文本「场景：A、B」→ 先挂 A 的所有素材场景，再挂 B 的；角色永远排在场景前面。
总数超过 9 张会截断并告警。
