# 分镜文本 → 标准任务文件

一份分镜提示词文本，产出两份可直接导入任务页的文件：

- `<输入文件名>.json`
- `<输入文件名>.xlsx`

一条 15 秒分镜 = 一条任务。提示词整段保留，不做摘要、不改写、不合并。

## 1. 素材库在哪：当前项目的 `assets/素材`（不问用户）

素材库就是当前项目的工作区，不用问、也不要让用户贴路径：

```
<项目目录>/assets/素材/
  人物/  第1集-错过，也是彼此成全/林清栀-三视图.png、第3集-被讨厌的勇气/温语-三视图.png ...
  场景/  第2集-慢下来，不是落后/大学图书馆通宵自习室.png ...
  道具/  （不进参考图，但目录存在）
```

素材按集分在子目录里，脚本会**递归**找图。项目目录这样拿：

- 跑命令时系统已注入 `WMD_PROJECT_DIR`（当前项目目录）和 `WMD_ASSETS_DIR`（`<项目>/assets/素材`），
  所以 `--assets` 一般**不用传**，脚本自己定位并会打印「素材库：…」；
- 想确认位置：`read_permission` 看根目录，或 `list_dir` 直接看 `assets/素材/人物`。

只有用户明确说「用另一个素材目录」时，才传 `--assets "<那个目录>"`。**不要**再问画幅、时长、字段、参考图顺序——这些规则是固定的：

| 项 | 规则 |
|---|---|
| 画幅 | 固定 `16:9`（`--ratio` 可改） |
| 时长 | 取每条记录的「时长：N秒」；没有则取 `[a-b秒]` 分段的最大值 |
| 标题 | `镜头 01` 起编号（`--title-prefix` / `--start-at` 可改） |
| 提示词 | 记录块原文整段，一字不删 |
| 参考图 | 只取「角色」+「场景」；「物品」不要 |
| Picture 标签 | 自动在提示词的 场景/角色/音色锁定 里插入 `<Picture n>`，n 与 images 顺序一致 |
| 不要的字段 | 分辨率、生成张数、参考音频路径、参考音频说明——一律不产出 |

## 2. 运行

```powershell
python scripts/build_tasks.py --input "分镜.txt" --out "output"
```

多集分批时加 `--episode 第3集`，只在「第3集-…」这类子目录里匹配，避免同一角色跨集串图：

```powershell
python scripts/build_tasks.py --input "第3集分镜.txt" --episode "第3集" --out "output"
```

输出示例：

```
素材库：D:\...\我的同桌测试-643a02\assets\素材（当前项目的 assets/素材）
只匹配这一集：第3集
✓ 15 条任务 · 61 张参考图 · 总时长 224 秒
  JSON  output\分镜.json
  Excel output\分镜.xlsx
  ! 第 6 条：本镜包含剪发前后两种造型，已同时挂上「林辰」长发/短发两张参考图
```

本机 `python` 可能是应用商店占位符（报 9009）。改用 DSH 自带解释器：

```powershell
& "$env:DSH_HOME\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe" scripts/build_tasks.py ...
```

没有命令权限（工作区档位）时不要硬跑脚本：用 `list_dir` 读 `assets/素材/人物`、`assets/素材/场景`（含各集子目录）拿文件名清单，按下面第 4 节的规则自己匹配。

## 3. 输入格式

以 `*::~RECORD::~*` 分块，`*::~OUTPUT_START::~*` / `*::~OUTPUT_END::~*` 可省略。一块就是一条任务：

```text
*::~OUTPUT_START::~*
禁止生成字幕，禁止生成背景音乐
场景：林辰家客厅｜内｜夜（傍晚）
角色：林辰、赵庭香、陈泽健
时间：傍晚
时长：15秒
物品：门钥匙
音色锁定：...
人物锚点：...
场景锚点：...
剧情承接：...

SHOT 1: Medium close-up, cut to Medium shot：...
林辰（现场对白・正常语速 / 平常报备语气 / 逗号微顿）：妈，我出去理个发。

SHOT 2: ...
*::~RECORD::~*
```

脚本只读 `场景`、`角色`、`时长` 三个字段做解析，其余内容原样留在提示词里。

## 4. 参考图怎么匹配

1. **角色**：先查 `mapping.json` 的 `aliases`（赵庭香→陈淑梅、陈泽健→陈择健、同班同学们→同学），再在 `人物/`（递归含各集子目录）里找以「角色名 + `_`」开头的图。
2. **同一角色多张图**（如林辰长发/短发）：看本条文本里的「长发 / 杀马特 / 短发」判断；没写的继承上一条；剪发那一镜两种都写，就同时挂两张。判断错了在 `mapping.json` 的 `character_pins` 里固定。
3. **场景**：`mapping.json` 的 `scenes` 把文本场景名映射成素材场景名（如 `旧社区理发店内及门外` → `理发店内` + `理发店门口`）；没配置的按文件名包含关系自动找。
4. **按集隔离**：素材放在 `人物/第3集-…/`、`场景/第3集-…/` 这类子目录里时，加 `--episode 第3集` 只在这一集的目录里匹配；不加就是全项目一起匹配，角色重名会串集。
5. **顺序**：先角色（文本顺序），再场景（文本顺序），相同文件去重；最多 9 张，超出截断并告警。

细节和调优见 [references/mapping.md](references/mapping.md)。

### Picture 标签（自动注入）

图片顺序定下来后，脚本会把 `<Picture n>` 写进提示词开头的三行，n 就是它在 `images` 里的序号：

```text
场景：<Picture 4>林辰家客厅｜内｜夜（傍晚）
角色：<Picture 1>林辰、<Picture 2>赵庭香、<Picture 3>陈泽健
音色锁定：<Picture 1>林辰：青年男性……；<Picture 2>赵庭香：中年女性……；<Picture 3>陈泽健：少年男性……
```

- 同一镜里一个角色有两张图（剪发前后）→ `<Picture 1><Picture 2>林辰`。
- 复合场景映射到两张图 → 两个标签连写。
- `images` 的 note 也以 `<Picture n>` 开头（JSON 与 Excel 一致），照着抄不会把标签打错。
- 只改这三行，其余行原样；不删任何原文。

## 5. 输出格式

JSON：

```json
{
  "version": 1,
  "items": [
    {
      "title": "镜头 01",
      "prompt": "整段原文……",
      "images": [{ "path": "D:/.../人物/林辰_封面同款蓝白校服_四视图_v1.png", "note": "<Picture 1> 角色：林辰（长发）" }],
      "duration": 15,
      "ratio": "16:9"
    }
  ]
}
```

Excel：第一张表「任务」6 列——分镜名称 / 视频提示词 / 参考图（按顺序）/ 参考图说明（按顺序）/ 视频画幅 / 视频时长；第二张表「填写说明」只读。字段与校验细节见 [references/format.md](references/format.md)。

## 6. 跑完要检查

- 结尾汇总的条数、参考图张数、总时长是否符合预期。
- 有 `!` 告警就逐条看：缺角色/缺场景说明素材库少了图；造型判断不准就加 `character_pins`。
- 建议再用应用的「任务管理 → 创建任务 → 分镜文件」解析一次，确认 0 错误再保存。

## 7. 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--input` | 必填 | 分镜文本 .txt |
| `--assets` | 当前项目 `assets/素材` | 一般不用传：先看 `WMD_ASSETS_DIR`，再看 `WMD_PROJECT_DIR/assets/素材`，最后从当前目录往上找 `assets/素材`（含 `人物/` `场景/`，递归含各集子目录） |
| `--episode` | 空 | 只匹配名字包含这段文字的那一集目录（例：`第3集`） |
| `--out` | `.` | 输出目录，不存在会自动创建 |
| `--name` | 输入文件名 | 输出文件名（不含扩展名） |
| `--ratio` | `16:9` | 画幅，可选 9:16 / 1:1 / 4:3 / 3:4 |
| `--title-prefix` | `镜头 ` | 标题前缀 |
| `--start-at` | `1` | 起始编号（多集接着编号用） |
| `--pad` | `2` | 编号位数 |
| `--map` | 本 skill 的 `mapping.json` | 别名/场景/固定图配置 |
| `--report` | 空 | 把汇总写成 JSON 文件 |

## 8. 常见问题

- **提示词超长**：单条超过 10000 字会报错（导入页的限制），需要拆镜。
- **时长不在 1–15**：脚本会留空并告警，用渠道默认值。
- **没装 openpyxl**：自动退回无样式 xlsx，照样能导入；想要样式就 `pip install openpyxl`。
- **分隔符不一样**：把分隔行改成 `*::~RECORD::~*`，或改 `scripts/build_tasks.py` 顶部的 `MARKER_RE`。
- **多集/多版**：一个文件跑一次，用 `--start-at` 接着编号，避免标题重复。

## 9. 不要做的事

- 不要删减、改写、摘要、合并提示词——用户明确要求整段保留。
- 不要把「物品」加进参考图。
- 不要新增分辨率、生成张数、参考音频路径、参考音频说明。
- 不要自己编图片路径：路径必须来自当前项目 `assets/素材` 里真实存在的文件（脚本输出的就是绝对路径）。
- 不要问用户「素材库在哪」——项目里就那一个，`assets/素材`。
