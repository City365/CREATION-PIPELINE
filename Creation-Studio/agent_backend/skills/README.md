# 后端标准技能目录（全局）

技能以后端目录为准，全局生效，换项目也能用：

```
agent_backend/skills/
  6-分镜提示词转批量任务格式/
    SKILL.md                     ← 入口，必填
    references/*.md|*.txt|*.json ← 可选，按文件名排序拼进技能正文
    mapping.json                 ← 可选（同上）
    templates/*.json             ← 可选（同上）
    scripts/ examples/           ← 源文件留存，不会被执行
```

## 后端怎么发现

智能体每次读取技能（`/agent/skills`、`/agent/plugins`、对话里选择技能、harness 冻结技能清单）时，会扫描这个目录：

1. 找到含 `SKILL.md` 的文件夹 → 按「创作台适配说明 + SKILL.md + 目录内文本文件（references / mapping / templates，跳过 scripts 与 examples）」合成技能正文；
2. 技能 ID 为 `dir:<文件夹名>`，直接合并进所有项目的技能列表，不写项目数据库；
3. 出现在插件管理、`@` 列表，并被 harness 冻结读取。

- 目录里同名技能只有一份；换项目、换数据目录都不会丢。
- 目录内修改后下一次请求生效，无需手动导入。
- 正文上限 60000 字符（`app/skills.py` 的 `SKILL_CONTENT_LIMIT`）；脚本不会被运行，只作源文件保留。
- 创建技能（文本 / 完整技能压缩包）都会写进这个目录；在插件管理里编辑或删除也会直接改目录。
