## D. 提示词结果
### 1）2×2 四视图合集提示词
输出一个 text 代码块：完整场景锁定描述 + 16:9 横版整图及等大 2×2 网格 + 左上正视/右上反视/左下侧视/右下俯视的具体机位与画面关系 + 四格共享固定对象/材质/光源 + 无人物、无额外家具、无布局翻转、无文字水印。不要将四格拼成四个不同场景。

### 2）正视图提示词
输出一个 text 代码块：完整场景和对象布局、统一外观与光照 + 本视角机位/目标/画角 + 可见主体/左右关系/遮挡 + 16:9 与约束。

### 3）反视图提示词
输出一个 text 代码块：独立完整场景描述 + 本视角条件；不得引用其他代码块。

### 4）侧视图提示词
输出一个 text 代码块：独立完整场景描述 + 本视角条件；不得引用其他代码块。

### 5）俯视图提示词
输出一个 text 代码块：独立完整场景描述 + 垂直正交去顶/北上西左/全边界覆盖 + 固定布局与约束。

说明：模板中的花括号、编写说明和本段说明不出现在最终结果中。五个提示词代码块都必须是可直接复制给图像模型的自然语言提示词，不保留模板占位符。
