# 基础风格预设

风格取自场景描述。未指定时采用写实。所有预设只调整视觉语言，不变更已确定的尺寸、位置、对象数量、机位和光源世界方位。

| 风格 | 材质与画面语言 | 光照与摄影 | 避免 |
|---|---|---|---|
| 古风 | 按描述确定朝代；未指定采用克制中式古典，木梁、木格窗、灰砖、素色织物，旧化适度 | 按时间使用窗光、烛光或灯笼；保留木纹与织物细节 | 无依据混搭朝代、现代电器、霓虹、欧式家具 |
| 写实 | 真实物理材质、准确比例、自然色彩、适度使用痕迹，室内建筑可视化 | 中性曝光、真实阴影、垂直线端正、水平透视 | 塑料质感、强锐化、过度广角 |
| 电影 | 真实布景、叙事色彩、层次化明暗、克制颗粒、保留暗部结构 | 描述决定冷暖和时间；可用柔和体积光，固定照明方向；维持四机位 | 为戏剧感改机位、过暗到无法辨认布局、凭空加烟雨 |
| 国漫 3D | 风格化 PBR、清晰轮廓、细腻木石材质、适度造型夸张 | 柔和全局光、层次分明、统一色调 | 夸张到破坏尺度、角色进入无人场景 |
| 二维动漫 | 干净线稿、明确色块、手绘背景质感、统一透视 | 赛璐璐或柔和绘景光影，四图同一画风 | 照片与手绘混杂、线条替代结构 |
| 白模 | 中性灰白、无装饰贴图，保留门窗、家具轮廓与尺寸 | 均匀工作光、环境遮蔽、可辨识体块 | 简化掉关键家具、增加尺寸文字、水印 |

组合示例：“古风电影感”采用古风资产与电影光照；“古风国漫3D”采用古风资产与风格化材质。不得把古风等同于夜景、电影等同于宽银幕或暗光。画幅默认仍为16:9，描述明确另定时四张单图与合集统一替换并报告。
