# 使用指导

将整个“场景4视图”目录作为技能包保存或导入，入口是 SKILL.md。无需先提供坐标、大小、道具表或机位。

固定输入只有：

场景名称：青竹书房
场景描述：古风木质书房，北墙书架，中间书案，西侧窗户透入午后光，东墙靠南开门，雅致安静。

尺寸、道具数量、门窗高度缺失时由技能补全，A 部分明确列出推定。想控制尺寸或风格，只需写在场景描述中。修改时保留原坐标模型和对象 ID，只更新用户要求的部分，再同步五条提示词。

固定输出 A 坐标系、B 对象表、C 摄像机、D 五条提示词。可以先用合集检查布局，再分别生成四张；各条提示词都能独立复制。当前技能负责文本设计，不调用图像生成服务。

脚本使用：

```bash
node scripts/check-layout.mjs examples/layout-example.json
```

在技能目录运行。脚本返回非零表示发现错误；它不执行渲染、不校验建筑规范。输入 JSON 是内部可选检查数据，不增加用户的输入字段。
