# 项目工作区与素材类型

## 项目根目录

- 设置项：设置 → 存储 → **项目根目录**（默认 `H3-Projects`，位于工程仓库同级目录，可改）。
- 每个项目在根目录下有一个独立子目录，创建项目时自动生成：

```
<项目根目录>/
  <项目名-编号>/
    assets/    素材库（图片/音频）
    media/     生成成片（视频/图片，按 日期/任务 分目录）
    uploads/   上传的临时参考文件
    exports/   导出文件
```

项目目录名在创建时确定（`项目名-编号`），之后改名不会移动目录。项目卡片上会显示目录路径。

## 读写规则

- **有当前项目时**：素材、成片、上传、导出只读写该项目的子目录；`/api/assets`、`/api/media`、`/api/jobs`、`/api/events` 默认只返回该项目的记录。
- **没有当前项目时**：回退到设置里的「未归档素材/成片目录」（旧版路径），只用于查看历史数据。
- 项目切换会同时切换：素材、媒体库、任务列表、创作台状态；服务端按登录用户的 `activeProjectId` 记住当前项目。
- 日志、任务、事件、图像任务仍在同一个 SQLite/JSON 库里，但每条记录带 `projectId`，查询、列表和执行归档都按项目过滤，不按项目拆库。
- 未归档（`projectId` 为空或 `unassigned`）的历史记录不会出现在项目视图里。

## 素材业务类型与分镜

素材库只有两类实体：

1. **根目录下的单个素材**：人物、场景、道具、首帧、尾帧、溶图参考、其他。类型写在 `data/assets.json`（按项目分开），可在页面上筛选和修改，不依赖文件名。
2. **顶层文件夹 = 一个分镜组**：一个分镜一个文件夹，里面放这个分镜的所有参考图；组内图片统一算「分镜参考」，不再区分人物/道具/场景。生成某个分镜时只从这个文件夹取图。

| id | 名称 | 用途 |
| --- | --- | --- |
| scene | 场景 | 环境、地点、背景 |
| character | 人物 | 角色外形、服装、身份板 |
| prop | 道具 | 物件、武器、关键物品 |
| firstFrame | 首帧 | 视频第一帧参考 |
| lastFrame | 尾帧 | 视频最后一帧参考 |
| blend | 溶图参考 | 构图、光影、色调融合 |
| storyboard | 分镜参考 | 分镜文件夹里的图片（只能通过分镜文件夹产生） |
| other | 其他 | 默认 |

- 页面：类型按钮一排；点「分镜参考」显示分镜文件夹卡片，进入后只显示该分镜的图片，可返回；「新建分镜」创建文件夹，之后上传的图都归入该分镜。
- 接口：`GET /api/assets`（返回 `items[].type/group` 与 `groups`）、`POST /api/assets/type`（仅限根目录素材）、`POST /api/assets/group`（新建分镜）、`POST /api/assets/move {rel,group}`（移入/移出分镜）、`POST /api/assets/upload {group?}`。
- 分镜里的图片不能单独改类型；移出分镜后恢复为普通素材（类型回到「其他」，可在详情里重设）。

## 智能体聊天记录

- 智能体会话同样按项目隔离：前端每次请求带当前项目的 `X-Project-Id`，后端 `conversations` 表以 `(project, id)` 为主键，运行记录、轨迹和压缩上下文也带 `project`。
- 切换项目时前端会中止当前生成、清空会话缓存并按新项目重新加载历史；旧项目的会话不会写到新项目下。
- 旧版本把所有会话统一存在 `h3-studio` 下；执行上面的迁移时会把它们归入当前项目，迁移前备份 `agent_backend/data/conversations.db`。
- 没有 `X-Project-Id` 的内部健康检查仍回退到 `h3-studio`，该命名空间不再用于正常聊天。

## 旧数据迁移

**不会自动迁移**。确认后手动执行：

1. 设置 → 存储 → **把旧数据迁入当前项目**。
2. 先备份到 `data/backups/workspace-<时间>/`，再把 `data/assets`、`data/uploads`、`data/media` 里的文件并入当前项目目录。
3. 结果写入 `data/workspace-migration.json`，重复点击会提示已迁移。

只处理应用自己数据目录下的默认旧目录；设置里指向外部目录的「未归档」路径不会被自动移动。
