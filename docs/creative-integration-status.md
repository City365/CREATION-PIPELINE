# 创作功能集成记录

日期：2026-10-24。对应 scene-modeling-plan.md 与 media-editing-plan.md 的首批可用链路。

## 当前入口

- 图像创作台 → 图层编辑：本地 miniPaint，支持图层工具、命名工程、自动保存、打开工程、导出新图片回画布。
- 图像创作台 → 场景建模：名称/描述和可选素材参考，选择推理/生图渠道，示例、AI 建模、平面坐标、对象属性/锁定、固定机位、白模/结构线稿、JSON 与提示词导出、当前机位结构引导生图。
- 媒体库 → 导入剪映（分集或单条成片）：把成片按镜头顺序写成剪映草稿，剪辑、字幕、混音与导出都在剪映里完成（内置剪辑工程已于 2026-10-28 下线）。

## 持久化与边界

工程按账号与项目划分，保存 revision 并拒绝旧版本覆盖。图层与场景工程分别保存（剪辑工程已下线）。源素材保留，编辑和导出均创建新图片/视频。

miniPaint 与 Three.js 固定版本、本地托管，见 web/integrations/THIRD-PARTY-NOTICES.md。没有引入 OpenCut 完整站点、云账号、Redis 或外部托管渲染服务。剪辑首版曾采用独立原生时间线，已整体下线，改为「导入剪映」生成草稿后由剪映处理。

当前场景几何检查包括数值/唯一 ID、旋转占地相交、高度区间、矩形范围与边界角点包含、墙面开口区间及机位嵌入。报告明确标记门扇扫掠、完整动线、图像一致性未检查。白模是尺寸体块，不是照片精细网格重建。AI 结果仍需要复核，停止等待不会声称取消已提交的上游请求。

当前剪辑仅主画面片段首尾相接，附加独立音频与手动字幕。精确剪辑会重新编码；没有宣称任意帧无损剪辑。高级转场、关键帧、自动转写、代理/波形以及可视化多画面叠加轨仍属于后续阶段。

当前图像编辑不承诺完整 PSD 往返、PS 插件或专业印刷色彩管理。高级工具质量以实际操作验收为准。

## 第二阶段进展

日期：2026-10-24。

- 剪辑新增主片段和配音轨波形，采用流式 PCM 分析与源文件指纹缓存，最多同时分析两份素材；可点击波形定位播放头。
- 支持导入 UTF-8 SRT，保留多行字幕，严格检查时间格式、数量与工程边界；追加操作可撤销。
- 支持片段内缩放/水平取景/垂直取景的线性关键帧。浏览器预览与 FFmpeg 导出共享计算规则；分割和裁切会继承取景状态，而不是丢失动画。
- 场景引导图改为16:9；增加显式地面薄层碰撞类型，适用于贴地且厚度不超过0.05米的地毯。未标记的对象仍按实体检查，不靠名称自动忽略碰撞。
- AI 机位嵌入家具时，可沿原朝向移动未锁定机位，保存调整前后坐标；家具保持不动，锁定机位不自动修改。

### 真实AI验收

1. 使用本地三维模型导出的结构线稿，经已配置的图像渠道真实生成一张书房场景图，约23秒，结果为实际PNG文件。
2. Gemini 对该场景图进行真实视觉反推，约47秒，识别书柜、书案、椅子、地毯和桌面物体，返回门窗与坐标模型；尺寸与部分属性明确标注推定。
3. 首次模型报告地毯与桌椅碰撞，以及反向机位嵌入书柜。审核后将地毯显式归为地面薄层，并由程序调整机位，基础几何检查通过。
4. 视觉检查仍发现：生成图补充了地毯/书籍等装饰，门的具体位置与原模型存在偏差。因此本次通过“真实调用、出图、视觉反推、冲突发现和修正链路”，不宣称米制精确重建或跨视图一致性通过。

测试图：媒体库/images/2026-10-24/img-c3ce595dae65-01.png。详细模型和复核记录保存在本地 data/scene-stage2-evidence.json（不纳入Git）。
