## 5. 评分计算

已执行单元全部适用维度达成率为 1：

`S = 100 × Σ(w×1) / Σ(w) = 100`

- 性能证据：10,000 条任务时单行 upsert p50 1.94 ms、p95 2.29 ms、max 18.58 ms（目标 < 20 ms）。
- 数据证据：本机 154 条任务迁移后行数与状态分布一致；`secrets` 表 10 行，`config.json`、`wmd.sqlite`、WAL 均无明文密钥；`/api/state` 泄露 0 次。
- 租户证据：`tenant_configs` 1 行；`secrets` 全部 `tenant/tnt_default`；双租户 API 测试中 B 看不到也用不了 A 的渠道；无上下文任务泵仍使用任务租户。
- UAT-008 未完成前，整体结论为「工程验证达标，INC-001 观察中」，不代签最终验收。
- 第二轮证据：22 个新增 Node 用例 + 5 个 Python 用例 + 4 个浏览器用例 PASS；`npm run test:offline` 543 个用例串行 PASS（排除 9 个付费 e2e）；见 RUN-008/009。
