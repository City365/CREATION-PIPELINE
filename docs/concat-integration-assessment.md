# Concat 智能剪辑接入可行性评估

后续已立项并开始实测，实际结果见 [验证项目记录](concat-validation-project.md)。下文保留立项前评估范围。

日期：2026-11-09。范围：本地源码与页面接线检查、上游文档核对；未构建、未启动编辑器、未验证视频导出。未修改现有业务代码。

## 决策建议

建议采用 Concat 作为可替换的剪辑执行底座，先保持原生编辑器，再补齐当前工程的实时编辑桥接。暂不将 Slint 原生界面嵌入网页，也不重写完整网页剪辑器。

这是有条件推进建议，不是运行验收通过。三个前置门槛是 Windows 构建成功、真实素材预览与导出一致、AI 与人工可以操作同一会话并共用撤销记录。

## 已查到的事实

- 本地已有 `Concat/` 源码。其 GUI 为 Rust + Slint，不是 HTML/Vue/React 组件。
- 引擎分为 project、media、render、export、host、api 等 crate；可通过接口复用，不必重做编辑语义。
- `Creation-Studio/web/smartcut.js` 已接入对话、MCP 状态、剪辑单和执行结果，现有实现定位为任务入口，不是交互时间线。
- `Concat/src/crates/concat-api/src/lib.rs` 的 OpenProjects 注册和 adopt 路径阻止 API 打开 GUI 持有的工程。
- `Concat/src/crates/concat/src/panes/settings.rs` 启动自动化服务时共享 exporter 和 open_projects，并未把 GUI 当前 Session 交给 API。
- `Concat/src/crates/concat-host/src/session.rs` 已有 apply、undo、redo；project 层已有 Batch 命令。可复用这些入口建设实时桥接，但仍需实现 UI 刷新、上下文传递、排队和版本冲突控制。
- 本机 Git Bash 可找到 Cargo，版本 1.98.1。本次 PATH 检查未发现 cmake，FFMPEG_DIR 未设置；不代表磁盘上没有这些依赖。未检查完整 C++ 工具链，也未执行构建。

## 路线比较

| 路线 | 判断 | 主要代价 |
| --- | --- | --- |
| 网页任务台 + 原生 Concat | 推荐首期 | 窗口切换；当前需关闭、移交、重新打开工程 |
| 二开原生 Concat，补实时桥接和助手入口 | 推荐核心方向 | Rust/Slint 维护、UI 事件循环调度、状态同步 |
| 网页界面 + Concat 后端引擎 | 可作为后续独立阶段 | 重建时间线交互、连续预览播放、音画同步、效果控件 |
| 把原生窗口嵌入网页 | 不建议 | 平台耦合、焦点和快捷键、DPI、窗口生命周期问题；非 iframe 接入 |

## 最小架构

Creation Studio 持有任务、素材索引和智能体上下文；Concat 的当前 Session 持有权威编辑状态。适配层传递明确工程 ID、片段 ID、范围、预期版本和操作 ID。所有修改在窗口事件循环中按序执行，以一组命令形成一次撤销；回复包含实际执行结果、最新版本、是否保存。网页只持有投影，不另设独立权威时间线。

首次实时功能只覆盖：读取当前工程；调整一条字幕和一个片段音量；GUI 立即显示；GUI 撤销；人工继续修改；AI 再次读取最新结果。不要先开放全部编辑命令。

## 验证顺序与通过条件

1. 原版构建：固定本地源码版本，补全依赖，构建并启动 Windows GUI。记录构建和启动错误。
2. 真实素材闭环：用用户日常分辨率、帧率、中文路径和字幕字体，执行导入、剪切、预览、保存重开和导出。检查黑帧、丢素材、音画同步、字幕及效果差异。
3. 接口闭环：读取能力和时间线，执行一批修改，检查结果、保存、重开及导出。当前 GUI 占用工程的拒绝行为应如实呈现，不能绕过锁写文件。
4. 实时桥接：同一 Session 的 AI 修改、人工修改、统一撤销、过期版本拒绝、取消与超时后结果核对。
5. 回接业务页面：传入项目素材和片段上下文；展示真实执行状态；保留人工打开工程入口。
6. 经验积累：记录意图、修改前后工程差异、人工修正原因和导出结果；经过确认的案例再进入检索规则与回归样例。

如预览导出稳定性不达标，保留现有剪映/FFmpeg 执行路径；如实时桥接暂未完成，应把产品定位为 AI 批处理 + 人工接手，不能宣称边看边改。

## 成本判断

相对成本：接口接入中低；Windows 构建与真实媒体兼容性中且不确定；实时共同编辑中高；完整网页化高。构建和媒体闭环通过前，不给确定工期。最大工作量不在聊天输入，而在工程会话一致性、实时播放及人工精调体验。

## 素材与授权边界

本地素材积累可减少重复检索和获取，但剪映专属效果、模板、字体和资源不一定可迁移为 Concat 可执行资源。分别记录来源、文件、依赖与可用引擎，不把缓存数量等同于替代率。

仓库标注 AGPL-3.0-or-later，并另有商业授权说明；Slint 等第三方依赖也有独立条款。公开分发或闭源产品决策需要结合实际组合方式审阅，不能仅凭进程隔离认定已解决授权问题。
