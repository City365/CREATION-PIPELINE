# 标签式智能体工作区验收

依据用户提供的 Codex 截图，替换上一版文件卡片工作区。右上角分为管理、摘要、新建标签页，文件浏览与摘要分离。

## 已实现

- 管理下拉菜单复用真实操作：重命名、置顶、新建对话、复制文本、导出、移动分组。点击外部或 Escape 关闭。
- 摘要展示项目、模型、权限、上下文参考占用、最近渠道输入用量、当前能力和真实产出清单。摘要可打开实际登记的工作文件和交付文件。
- 新建标签页打开独立工作区起始页；点击文件显示项目实际目录树，不再展示卡片列表。
- 点击树中文件，新建独立预览标签；文件树与预览并存，选中项高亮。支持多个标签切换、关闭、工作区展开及关闭。
- 展开、折叠及预览切换保留已加载目录与滚动状态；目录按需读取，每批最多 50 项，可继续加载。筛选明确作用于已展开目录。
- 目录树以主服务确认的项目根为边界，拒绝逃逸和内部隐藏索引目录；已有文件原地登记，无重复复制。浏览图片不会触发 AI 识别。
- 文件预览复用现有 Markdown、文本/脚本、表格、图片、PDF、音频和视频展示。HTML 继续隔离且不执行脚本。
- 工作区打开时临时收起左侧会话目录，关闭后恢复，避免挤压对话输入区域；会话目录仍可独立展开。
- 样式独立为 web/agent-workspace.css，避免其他全局样式修改覆盖工作区布局。

## 验收

- 创作台完整 npm test：288 passed，0 failed，包含 3 个新增标签/目录树行为测试。

- 正式服务确认：主服务和智能体在线，/agent/workspace/tree 与 /agent-workspace.css 返回 200。
