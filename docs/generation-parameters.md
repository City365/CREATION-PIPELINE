# 前置提示词、图片比例与分区样式

图像与视频创作台均增加独立的“前置提示词”参数框。默认显示项目风格；可编辑、清空，或点击“使用项目风格”恢复继承。图像前置词可选择人物、场景、道具、通用或按正文自动选择。

图像新增 16:9、9:16、4:3、3:4 比例与关联的分区样式：

| 适用比例 | 样式 | 分区 |
| --- | --- | --- |
| 16:9、4:3 | 胸像＋三视图 | 左侧宽度 1/3 为胸部以上特写；右侧宽度 2/3 横向三等分，分别为全身正面、右侧、背面 |
| 16:9、4:3 | 胸像＋服装三视图 | 保留左侧完整胸像，右侧三格为颈部以下至双脚的正面、右侧、背面服装展示 |
| 9:16、3:4 | 四宫格 | 上排高度 1/3，为正面头像和侧脸；下排高度 2/3，为全身正面和背面 |
| 9:16、3:4 | 服装展示四宫格 | 上排保持完整头像，下面两格裁切为颈部以下至双脚的正面、背面服装展示 |
| 全部四种比例 | 自由构图 / 自定义分区 | 自由填写每个小块的内容 |

选择样式会显示预设分区示意及可编辑的分区说明。切换比例时，不兼容的布局会重置为自由构图。图像画布的数量仍指生成图片张数，分区样式指每张图片内部的布局。

前置词、比例、布局 ID、分区说明按当前画面/分镜持久化到 SQLite，并保存到生成快照。请求按“前置词 → 比例和布局说明 → 用户正文”组装，正文保持独立；视频请求按“前置词 → 用户正文”组装。重新生成沿用原快照，不重复叠加前置词。

比例和像素尺寸为两个独立参数。所有渠道会收到提示词中的比例与构图要求；Gemini 图像渠道额外发送原生 imageConfig.aspectRatio，且同时保留 imageSize。OpenAI / Chat 兼容渠道继续使用渠道支持的 size，不强行发送不受支持的分辨率；这些渠道的比例遵从度取决于实际模型，界面中的渠道分辨率参数保持独立，不在生成后强制裁剪图片。

Gemini 字段依据：[官方图像生成文档](https://ai.google.dev/gemini-api/docs/generate-content/image-generation)。

验证：66 项回归测试通过；分镜浏览器验收及图像后台任务浏览器验收通过。新增覆盖包含四种比例关联、分区组装、前置词只提交一次、视频前置词组装、Gemini 原生比例与分辨率同时保留、画面参数刷新恢复。

验证使用本地模拟渠道，没有向真实供应商发送额外生成请求。
