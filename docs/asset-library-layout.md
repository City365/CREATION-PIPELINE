# 素材库结构（分镜 / 素材 / 其他）

素材库按项目隔离，目录固定在项目目录下：

```
WENYUN.M-DESKTOP-Projects/<项目名-编号>/assets/
  分镜/
    <任务>/
      task.json
      镜头01/
        图一.png
        图二.png
        ...
        图九.png
        shot.json
      镜头02/
  素材/
    人物/
    场景/
    道具/
  其他/
  .版本/          ← 同名资产被重新生成时，旧图自动留档（点开头，素材树不显示）
```

## 路径规范

素材库里的路径一律是**相对项目目录**的（例如 `assets/素材/人物/第1集-…/林清栀-三视图.png`），接口和记录里都用这种写法，绝对路径只在运行时现算。原因：项目根目录是用户在设置里自己选的，换盘/换目录之后绝对路径全断，相对路径跟着根走。

- 接口用 `rel`：`GET /api/assets/dir?rel=素材/人物`、`GET /api/assets/file?rel=…`；不带盘符、不以 `/` 开头、不用 `..`。
- 智能体出资产图时传 `target_path`（`generate_image(target_path="assets/素材/人物/<集>/<角色>-三视图.png")`），图就固定落在那个位置。
- 同名重新生成不是再加一个 `(2)`：写回同一个路径，旧图移到 `assets/.版本/<原目录>/<时间>-<文件名>`，所以资产链接永远指向最新版，历史也还在。

## 页面

左侧菜单三级：

- **分镜**（一级）
  - **任务**（二级，带任务 id）
    - **镜头**（三级）
- **资产**：人物 / 场景 / 道具，右侧展示该分类下的图片，可上传。

点击任务展开镜头，点击镜头后右侧固定 9 个图框（图一 ~ 图九）。

每个图框支持：

- 本地上传 / 替换 / 清除；
- 从素材库（人物、场景、道具）选择，复制到该格；
- 文件落盘为 `图一.<扩展名>` ~ `图九.<扩展名>`。

## 管理

- 任务：可新建、展开/收起、重命名、删除（带确认）；
- 镜头：可新建、重命名、删除（带确认）；
- 素材：上传、搜索、重命名、删除；
- 删除任务只删任务目录和镜头副本，`素材/` 原图不受影响。

## shot.json

每个分镜目录里有一份 `shot.json`，保存这一镜解析出来的内容：

```json
{
  "title": "镜头01",
  "prompt": "雨夜街头，镜头缓慢推近",
  "prefixPrompt": "电影感，35mm 胶片，冷色调",
  "duration": 10,
  "ratio": "16:9",
  "images": [
    {
      "path": ".../assets/分镜/<任务>/镜头01/图一.png",
      "name": "图一.png",
      "note": "女主正面",
      "slot": "图一",
      "sourcePath": ".../素材/人物/女主.png"
    }
  ],
  "slots": { "图一": { "...": "..." } },
  "extra": {},
  "source": "shots.json",
  "importedAt": 1760000000000
}
```

- `images` 只保留有图的格子，顺序对应图一到图九；
- `slots` 按「图一」…「图九」记录，删除图后同步移除；
- 任务级 `task.json` 记录任务 id、标题和来源文件。

## 与创建任务的联动

在 **任务管理 → 创建任务** 上传分镜 JSON / Excel 后：

1. 解析只生成预览表格，**不会写素材库**；
2. 点「保存任务」创建任务后，才按任务 id 建 `assets/分镜/<任务>/`；
3. 任务下按镜头建目录，写入 `shot.json`，参考图复制为图一 ~ 图九；
4. 打开素材库 → 分镜 → 任务，展开后就能看到镜头和图片。

同一个任务再次保存会更新原任务目录，不会新建一堆重复分镜。

## 兼容

- 旧版素材库接口 `/api/assets` 仍保留，供创作台/图像参考图选择使用；
- 新页面使用 `/api/assets/library`，只读新结构；
- 旧根目录文件不会自动搬移，避免再次出现迁移丢文件。
