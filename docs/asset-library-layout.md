# 素材库结构（分镜 / 素材 / 其他）

素材库按项目隔离，目录固定在项目目录下：

```
H3-Projects/<项目名-编号>/assets/
  分镜/
    镜头01/
      图一.png
      图二.png
      ...
      图九.png
      shot.json
    镜头02/
  素材/
    人物/
    场景/
    道具/
  其他/
```

## 页面

左侧菜单：

- **资产**：人物 / 场景 / 道具，右侧展示该分类下的图片，可上传；
- **分镜**：每个 `assets/分镜/` 子文件夹一个菜单项，右侧固定 9 个图框（图一 ~ 图九）。

每个图框支持：

- 本地上传 / 替换 / 清除；
- 从素材库（人物、场景、道具）选择，复制到该格；
- 文件落盘为 `图一.<扩展名>` ~ `图九.<扩展名>`。

## shot.json

每个分镜目录里有一份 `shot.json`，保存这一镜解析出来的内容：

```json
{
  "title": "镜头01",
  "prompt": "雨夜街头，镜头缓慢推近",
  "duration": 10,
  "ratio": "16:9",
  "resolution": "",
  "count": null,
  "images": [
    {
      "path": ".../assets/分镜/镜头01/图一.png",
      "name": "图一.png",
      "note": "女主正面",
      "slot": "图一",
      "sourcePath": ".../素材/人物/女主.png"
    }
  ],
  "slots": { "图一": { "...": "..." } },
  "audios": [],
  "extra": {},
  "source": "shots.json",
  "importedAt": 1760000000000
}
```

- `images` 只保留有图的格子，顺序对应图一到图九；
- `slots` 按「图一」…「图九」记录，删除图后同步移除；
- 页面上的「保存提示词」会更新 `prompt` 并立即写回这个文件。

## 与创建任务的联动

在 **任务管理 → 创建任务** 上传分镜 JSON / Excel 并解析成功后：

1. 自动按每条分镜的标题创建 `assets/分镜/<标题>/`；
2. 把解析出的提示词、时长、画幅、分辨率、张数、扩展字段写进 `shot.json`；
3. 把参考图复制为图一 ~ 图九（最多 9 张），原图仍保留在原路径；
4. 打开素材库 → 分镜即可看到新分镜和图片。

点「保存任务」时还会再同步一次，保证表格里改过的标题、提示词、画幅、时长覆盖到 `shot.json`。

## 兼容

- 旧版素材库接口 `/api/assets` 仍保留，供创作台/图像参考图选择使用；
- 新页面使用 `/api/assets/library`，只读新结构；
- 旧根目录文件不会自动搬移，避免再次出现迁移丢文件。
