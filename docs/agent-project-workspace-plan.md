# 智能体随项目工作区统一存储实施计划

状态：方案评审，尚未修改业务代码或迁移用户文件。

## 目标与现状

项目目录是业务文件唯一归属。智能体工作区是项目内的一个目录，对话是文件的来源视图。当前项目示例：D:/notebook/AIGC/WENYUN.M-DESKTOP-Projects/我的同桌测试-643a02。

源码依据：Creation-Studio/src/workspace.js:12–33 已提供 assets/media/uploads/exports；agent_backend/app/workspace.py:9、44–50、106–124 将每次上传写入全局 ROOT/file_id；create_artifact:150–184 又调用 save_upload。fs_tools.py 的 publish_artifact 读取原文件后创建交付副本，xlsx 还会重建工作簿，存在不必要副本和格式丢失风险。permissions.py:83–100 已有项目路径查询，但失败退缓存，不适合作为新写入的最终路径权威。

## 目录规则

项目根/
  assets/素材/                   正式人物、场景、道具图片，沿用当前分类
  assets/分镜/                   正式分镜图片及现有业务数据
  media/                         正式视频、音频等，沿用现有规则
  exports/                       用户主动导出的打包文件、交付件
  uploads/                       既有创作台上传目录
  智能体工作区/
    对话/20261031-资产提取-s_短ID/
      输入/                      本次从项目外上传的新附件
      文档/                      分析、提示词、评审及草稿文档
      脚本/                      Python、JS 等脚本
      临时/                      本轮中间文件，不自动当成正式交付
      版本/                      同一文件修改前的历史版本
      会话记录.md                可读对话导出，不含模型隐藏思考
      文件清单.json              本对话文件关联及相对路径的可导出清单
    .索引/workspace.sqlite       项目级文件、会话及版本元数据

目录由稳定 sessionId 关联；会话重命名只改显示名，不反复改磁盘路径。空子目录按需创建。索引数据库应包含 schema_version；项目内保存会话/执行记录及文件关系，供项目搬迁后恢复。全局数据库保留项目注册、账户及模型配置；既有会话存储采用双读迁移，不在第一阶段同时替换整个执行器。

会话记录.md 便于用户查看，但结构化记录才是恢复依据。记录用户输入、最终回复、公开工具事件及已提交参数，不记录密钥、认证头或模型隐藏思考。

## 一份实体、多处引用

1. 项目外附件上传：保存到本对话输入目录，记录摘要、来源、fileId；同对话重复提交同一附件按请求编号和内容摘要去重。
2. 项目已有图片或文件：注册原位置，默认不复制、不移动。跨对话共享同一文件，用关联表表达；不因同内容而混淆不同语义资产。
3. 智能体生成文档/脚本：默认写入当前对话文档/脚本目录；创建文件即登记，未调用 publish 也能在“工作文件”看到。publish 改成核验并标记交付状态，不重建内容。
4. 图像/视频任务：明确传入 projectId/sessionId/runId，结果直接进入既有 assets/media 规则；工作区登记引用，保留生成提示词、参数、参考图、来源任务 ID。
5. 文件晋升：文档变成正式业务资产时执行一次显式注册或受控移动；fileId 不变，原会话引用随之更新，历史版本保留。
6. 导出才创建交付副本，并标注导出来源。预览、发布、添加到会话均不隐式复制文件。
7. 同名处理：同 fileId 更新产生版本；新的同名文件采用可读编号或短 ID，绝不静默覆盖。xlsx 原始字节保留，预览解析不改写工作簿。

## 定位与权限

- 主服务按 projectId 解析真实项目根，后端不接受模型传入任意项目根。存储使用 projectId + root-relative path + fileId，绝对路径在访问时解析。
- 每次运行冻结 projectId/sessionId 和工作区根版本。用户切换到项目 B，项目 A 的在途任务继续写回 A，绝不跟着界面切换；新任务使用 B。
- 找不到项目根、路径不可用、项目已迁移时停止新写入并给出可恢复错误，不能静默回到后端 data/workspace；迁移前验证并阻止仍向旧根写入。
- 项目根整体迁移需有注册/重新绑定流程；不能只更新一个全局变量。进行中的运行完成或暂停后，再切换根和失效缓存。
- 访问文件前校验项目归属、相对路径和真实路径（含符号链接/junction），拒绝逃逸。权限扩大必须显式配置。
- 默认文件和命令工作目录为本次对话目录；获准的正式写入可指向本项目资产目录。通用命令的工作区隔离问题作为前置修复处理；仅更改 cwd 不能构成隔离。

## 数据与接口

项目索引至少提供 files、file_versions、session_files、file_events、runs/session_export 相关记录。核心字段：fileId、projectId、sessionId、runId、messageId、relativePath、category、origin、hash、version、状态、createdAt/updatedAt、引用任务 ID。一个文件可关联多会话，不能把唯一 session_id 当作物理归属。

保留现有 fileId 下载/预览接口，对外不以绝对路径作为身份。增加登记已有文件、文件版本、来源定位、当前会话文件分页接口。工具写文件成功后登记，登记失败须标记为未索引并可扫描恢复；进程崩溃后可核对清单与磁盘。任意脚本创建文件由运行结束的增量扫描补登记，只扫描对话目录或明确输出目录，不递归扫全项目。

数据库中的提取文本是搜索缓存，不是第二个实体文档，缓存可重建。脚本文件可以下载和语法高亮，不能作为 HTML 执行；HTML 预览继续隔离。

## 前端

右侧显示“产出文件 / 输入材料 / 执行过程”，删除无助于当前对话的技能数量等统计。产出文件默认只展示当前会话关联文件，交付件与工作文件用状态区分；图片、文档、脚本、视频可筛选，每页 10 条，按需加载预览。

文件卡提供预览、打开所在位置、复制路径、下载、版本、来源轮次。已经在 assets/素材 的图直接展示其真实位置。手动改名/移走造成索引失联时显示“文件已移动或缺失”，允许重新定位；禁止自动生成空文件假装恢复。移除对话引用和删除实体文件是不同操作，共享文件删除前检查引用，使用项目回收站。

## 实施阶段

### 第一阶段：路径统一与可靠登记

扩展 src/workspace.js 提供 agent 路径；新增后端统一路径解析/文件注册服务；项目归属守卫；默认 cwd；新建文档和上传落到项目内。保留旧文件读取分支，不再新增全局 file_* 实体。密钥配置不随项目文件导出。

### 第二阶段：交付与生成贯通

publish_artifact 改登记已有文件，避免复制；文件工具写入/修改接入版本记录；支持 .py/.js 等脚本作为纯文本文件；图像/视频产物补齐会话关联和生成来源。先使用旧会话数据库并写项目级可恢复会话导出，随后在兼容验证后切换项目级会话存储，避免一次大改。

### 第三阶段：历史迁移

只读盘点 workspace_files 的 project、session、collection、source 与真实文件；生成逐文件迁移清单。对能确认项目的文件复制到目标并验证 SHA-256、大小和索引，保留原 fileId；更新索引后验证预览/下载/原消息链接，再将旧目录标记为已迁移。原文件在验收前不删除。

已有项目文件和发布副本，只有来源及内容一致且归属明确才合并引用；不能凭文件名或 hash 自动合并业务资产。无法确定项目、孤立文件、缺失文件以及知识库共享文件分别列出，等待归属决策，不强行塞进当前项目。迁移脚本可重复运行、有检查点、支持回滚，整段迁移期间对该项目写入互斥。旧数据备份包含数据库及实体文件，不能只备数据库。

### 第四阶段：工作区界面与完整验收

上线产出文件视图、版本和来源跳转，补文件监听/增量刷新；验证刷新和切项目后恢复，最后切换默认入口。导出完整项目或迁移项目时携带 agent 文件和索引，提供重建检查。

## 验收标准

- 项目 A 上传剧本、生成文档和脚本、生成图片后，实体均在 A 项目内；后端旧 workspace 无新增业务文件。
- 发布已有文件前后字节哈希一致，不新增内容副本；Excel 格式/公式不因发布重建。
- 同文件跨两次对话引用可追溯，更新产生版本；删除一个会话不删除另一个会话使用的文件。
- A 正在运行时切到 B，A 结果仍归 A；B 无法使用 A 的 fileId 读取或修改。
- 进程中断发生于文件落盘后、登记前，可恢复索引，不重复生成文件；提交重试保持幂等。
- 项目根搬迁后重新绑定，预览、下载、媒体引用及会话来源仍有效；根不可用时明确报错。
- 历史迁移可中断、重跑、回滚；旧消息链接保持有效，未归属文件有清单。
- 前端默认显示当前对话真实产物，10 条分页；技能数量不占工作区。

实施顺序：权限与路径权威 → 新文件统一落盘 → 无复制发布/生成来源 → 迁移 → 前端与搬迁验收。此计划不执行用户文件迁移。
