# 任务生命周期分工

## 创建（创建任务页）

1. 填：任务名称、视频生成渠道、视频模型（图像任务只有渠道）。
2. 上传分镜文件（JSON / Excel），解析后立即显示错误和提醒；出错的行会标出来。
3. 解析结果是一张可编辑表格：每个分镜一行，可改分镜名、提示词、画面比例、时长，可删除/新增分镜、移除参考图；素材列按上传顺序列出文件与说明。
4. 点「保存任务」只创建任务，不执行、不消耗额度。
   - 单条任务也用一个文件（一行）。

## 调度（任务调度页）

只区分两种归属，不显示执行过程：

- **未分配**：刚保存的任务，还没有运行时间。
- **已分配**：已经配置过运行时间的任务。

「配置调度」设置运行时间、并发数量、失败处理和执行次序：

- 运行时间留空 = 保存后立即执行；
- 指定时间 = 到点自动开始；
- 列表按「执行次序 → 运行时间」排序；执行中的任务不能改调度。

待调度任务在详情里可以 **编辑 / 取消 / 删除**，调度页行内也有取消和删除：

- 编辑：回到创建页，改完重新保存，仍停在待调度；
- 取消：进入「已取消」，从调度页消失；
- 删除：只有草稿、待调度、已取消可以删；已排期 / 执行中 / 已结束必须先取消；
- 删除会同时移除任务和它的执行记录，不能恢复。

调度、监控、日志都和任务管理一样按每页 10 条分页。

## 状态流转

```
保存任务 → 待调度（未分配）
配置调度 → 待执行（已分配，未到时间）
到点/立即 → 执行中
结束 → 完成 / 部分失败 / 失败 / 已取消 / 待确认
```

任务管理页只显示状态和进度；调度页只管分配；执行细节在监控页。

## 失败后只改一条提示词

被平台判违禁、或只是某一句写错时，不用重传整个文件：

1. 打开任务详情，找到状态为「失败 / 已取消 / 已跳过」的分镜；
2. 点「改提示词」，只改这一条的视频提示词和前置提示词；
3. 「仅保存」只更新这一条，不消耗额度；「保存并重试」才会按新内容重新提交这一条；
4. 其它分镜、参考图顺序、任务本身都不变。

已保存但还没调度的任务，仍可在任务管理里点「编辑任务」，在表格里改完再保存。

## 监控（任务监控页）

记录每个任务的配置操作和每个条目的执行记录：

- 配置操作：保存任务、配置调度（时间/并发）、暂停、继续、取消等，带时间；
- 执行记录：每个分镜的开始时间、耗时、状态、错误；
- 顶部「近 7 天报告」保留汇总视图。

## 日志（日志页）

按任务列出每个分镜（小任务）的运行状态和结果，可打开单个分镜的完整日志。

## 媒体库与成片命名

- 媒体库只读取**当前项目**的 `media/`，页头可切换项目和显示路径；列表按任务分组，卡片显示「分镜名称 · 文件名」。
- 新生成的视频直接按分镜名称落盘：分镜名称是「镜头 01」就是 `镜头 01.mp4`，是「分镜 3」就是 `分镜 3.mp4`。
- 旧成片或失败重试后文件名不一致时，点媒体库右上角「按镜头名重命名」：先预览旧名 → 新名，确认后文件名改成对应分镜名称；只改文件名，不动视频内容。

## 豆包参考图 @

第 6 张起，豆包的候选不会自动滚出来：在输入框输入 `@` 后继续输入图片文件名，候选出现后再点选。管理器现在对每一张图都先输入 `@ + 文件名`，不再只输入 `@`。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/events` | 创建任务；`pendingSchedule: true` 表示保存后待调度 |
| POST | `/api/events/:id/prepare` | 把草稿标为待调度 |
| POST | `/api/events/:id/schedule` | 配置运行时间、并发、失败策略 |
| GET | `/api/events/:id/attempts` | 执行记录 |
| GET | `/api/events/:id/items/:itemId/log` | 分镜日志 |
| POST | `/api/events/:id/items/:itemId/revise` | 只改这一条分镜的提示词（失败/取消/跳过） |
