# 智能体项目选择与多目录工作区

项目入口位于对话输入框上方（含空白新对话），点击显示可搜索项目列表、新建项目入口。原左侧“新建项目”实际是对话分组，已改名“新建分组”。

创建项目时填写名称，通过本地目录浏览器添加已有目录；支持继续添加、移除、设为主要。第一个目录为主要工作区，项目素材、媒体、上传、导出和智能体工作区放在该目录，不复制原有目录。其他目录保存到项目 sourceFolders，供文件工具在工作区权限下操作。旧项目原路径保持兼容。

工作区权限解析当前项目登记的全部目录并解析真实路径；未添加目录继续受限。完全权限沿用现有范围与系统保护。切换项目按项目 ID 隔离目录缓存。任务生成中暂不允许从该入口切换项目。

验收：293 项 Node 回归通过；19 项权限测试通过（包含多目录允许、未添加目录拒绝、切换项目隔离、完全权限）。实际浏览器完成搜索、选择已有项目、添加两个目录创建、刷新回读。正式 17821 与 17820 服务重载后健康检查为 200，本地目录接口可用；未提交 AI 生成。

## 系统文件夹选择更新

“添加文件夹”改用 Windows 原生文件夹对话框（Python Tk/Windows shell），移除网页逐层目录浏览器及目录枚举 API。系统对话框返回真实绝对目录，取消不添加，重复目录不添加，可继续添加多个源目录。新增选择、取消、异常处理测试 3 项，与项目目录测试共 6 项通过。
