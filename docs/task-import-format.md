# 任务文件导入格式（JSON / Excel）

任务创建只接受固定格式的文件，单条任务也用一个文件（一行 / 一个 item）。
这样做是为了让「页面提交的内容」与「执行器收到的参数」只有一个来源，避免两条创建路径产生不兼容的载荷。

入口：任务管理 → 创建任务 → 任务文件。

## 使用流程

1. 选择视频 / 图像，选择渠道。
2. 点「下载 JSON 示例」或「下载 Excel 示例」。
3. 按模板填好内容（参考图路径写在文件里）。
4. 上传文件，页面解析并显示条目预览、参考图数量与错误行号。
5. 修正到没有错误后，保存草稿或加入队列。

## Excel（.xlsx）

第一张表解析，第一行表头必须完全一致（顺序固定，不支持增删列）：

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 任务标题 | 否 | 留空时用提示词开头代替 |
| 提示词 | 是 | 一段话描述画面、主体动作、镜头与光线 |
| 参考图路径 | 否 | 绝对路径，或相对素材库的路径；多个用英文分号 `;` 分隔 |
| 参考图说明 | 否 | 与路径一一对应，说明这张图是什么（角色 / 首帧 / 场景） |
| 时长（秒） | 否 | 1–15 的整数；留空用渠道默认值；图像任务忽略 |
| 画幅 | 否 | `16:9` / `9:16` / `1:1` / `4:3` / `3:4`；留空用渠道默认值 |
| 分辨率 | 否 | 官网 API 渠道的分辨率（如 `768p竖`）；留空用渠道默认值 |
| 生成张数 | 否 | 图像任务一次生成几张，1–4；视频忽略 |

第二张表「填写说明」只用于阅读，不参与解析。

## JSON

```json
{
  "version": 1,
  "items": [
    {
      "title": "镜头 01",
      "prompt": "雨夜的旧城街道，镜头缓慢推近。",
      "images": [
        { "path": "D:/素材/ref-01.png", "note": "女主正面" },
        { "path": "D:/素材/ref-02.png", "note": "女主背影" }
      ],
      "duration": 10,
      "ratio": "16:9",
      "resolution": "",
      "count": 1
    }
  ]
}
```

- 顶层必须是对象，且含 `items` 数组；不支持一行一条的文本、CSV、`.xls`。
- `images` 里的 `path` 与 Excel 的参考图路径规则一致；`note` 对应参考图说明。
- `duration` / `ratio` / `resolution` / `count` 可省略，省略时用渠道默认值。
- 未知字段会被忽略，不报错。

## 校验与报错

- 解析阶段检查：表头、提示词为空、参考图文件是否存在、时长 / 画幅 / 张数取值、参考图不超过 9 张。
- 错误按行号返回（Excel 用实际行号），页面上整块列出；只要还有错误，保存 / 入队按钮会拒绝提交。
- 渠道限制（例如某工作流只支持 5–15 秒）在创建时校验，错误显示在创建页底部。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/task-import/template?format=json` | 下载 JSON 模板 |
| GET | `/api/task-import/template?format=xlsx` | 下载 Excel 模板（含填写说明表） |
| POST | `/api/task-import/parse` | `{ name, data }`（`data` 为 base64），返回解析后的条目、错误与统计 |

模板由 `src/task-import.js` 生成；XLSX 的读写不依赖第三方库（ZIP + 表格 XML），可直接用 Excel / WPS / openpyxl 打开。
