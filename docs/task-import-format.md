# 任务文件导入格式（JSON / Excel）

任务创建只接受固定结构的文件，单条任务也用一个文件（一行 / 一个 item）。
这样「页面提交的内容」与「执行器收到的参数」只有一个来源，避免两条创建路径产生不兼容的载荷。

入口：任务管理 → 创建任务 → 分镜文件。

## 使用流程

1. 选择视频 / 图像，选择渠道与模型（一个渠道有多个模型时才需要选模型）。
2. 点「JSON 示例」或「Excel 示例」下载模板。
3. 按模板填好内容（参考图、参考音频路径写在文件里）。
4. 上传文件：解析后是一张可编辑表格，每个分镜一行，可以直接改标题、提示词、画幅、分辨率、时长、张数，也能删除 / 新增分镜和素材。
5. 解析成功会自动同步到素材库：按分镜标题建 `assets/分镜/<标题>/`，参考图写成图一 ~ 图九，解析结果写进 `shot.json`；保存任务时会再同步一次表格里改过的值。
6. 确认无误后点「保存任务」；任务进入调度页的「未分配」，不会立即执行。

## Excel（.xlsx）

第一张表解析，第一行是表头。**按列名识别，顺序可以调整**；缺少「提示词」列才会报错。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 任务标题 | 否 | 留空时用提示词开头代替 |
| 提示词 | 是 | 一段话描述画面、主体动作、镜头与光线 |
| 参考图路径 | 否 | 绝对路径，或相对素材库的路径；多个用英文分号 `;` 分隔 |
| 参考图说明 | 否 | 与路径一一对应，说明这张图是什么（角色 / 首帧 / 场景） |
| 时长（秒） | 否 | 1–15 的整数；留空用渠道默认值；图像任务忽略 |
| 画幅 | 否 | `16:9` / `9:16` / `1:1` / `4:3` / `3:4`；留空用渠道默认值 |
| 分辨率 | 否 | 渠道支持的分辨率（如 `768p竖`）；留空用渠道默认值 |
| 生成张数 | 否 | 图像任务一次生成几张，1–4；视频忽略 |
| 参考音频路径 | 否 | 只给接收音频的视频渠道用，多个用分号 `;` 分隔，最多 3 段 |
| 参考音频说明 | 否 | 与音频路径一一对应，例如「女主音色」 |

模板之外的列不会被丢掉：解析时按原值保留，页面会提示「未识别的列会按原值保留」，表格底部以「扩展」显示。
第二张表「填写说明」只用于阅读，不参与解析。

## JSON

```json
{
  "version": 1,
  "items": [
    {
      "title": "镜头 01",
      "prompt": "雨夜的旧城街道，镜头缓慢推近。",
      "images": [
        { "path": "D:/素材/ref-01.png", "note": "女主正面" },
        { "path": "D:/素材/ref-02.png", "note": "女主背影" }
      ],
      "audios": [
        { "path": "D:/素材/voice-01.mp3", "note": "女主音色" }
      ],
      "duration": 10,
      "ratio": "16:9",
      "resolution": "",
      "count": 1
    }
  ]
}
```

- 顶层必须是对象，含 `items` 数组（兼容旧文件的 `tasks` 数组，会给一条提醒）。
- `images` / `audios` 里的 `path` 与 Excel 的路径规则一致；`note` 对应说明。
- `duration` / `ratio` / `resolution` / `count` 可省略，省略时用渠道默认值。
- 常见别名也能识别：`aspectRatio` → 画幅、`seconds` → 时长、`refs` → 图片、`name` / `shot` → 标题、`subject` → 说明。
- 不认识的字段不会丢：原样放进 `extra`，并在页面上提示字段名；也可以在 item 里显式写 `"extra": { "景别": "中景" }`。
- 旧的 `tasks`、`aspectRatio`、`audios`、`extra` 都能解析，不需要改文件。

## 校验与报错

- 解析阶段检查：提示词为空、参考图 / 音频文件是否存在、时长 / 画幅 / 张数取值、参考图不超过 9 张、音频不超过 3 段。
- 错误按行号返回（Excel 用实际行号），页面上整块列出；只要还有错误，保存按钮会拒绝提交。
- 渠道限制（例如某模型只支持 5–15 秒）在保存时校验。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/task-import/template?format=json` | 下载 JSON 模板 |
| GET | `/api/task-import/template?format=xlsx` | 下载 Excel 模板（含填写说明表） |
| POST | `/api/task-import/parse` | `{ name, data }`（`data` 为 base64），返回解析后的条目、错误与统计 |

模板由 `src/task-import.js` 生成；XLSX 的读写不依赖第三方库（ZIP + 表格 XML），可直接用 Excel / WPS / openpyxl 打开。
