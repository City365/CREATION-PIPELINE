# 任务文件导入格式（JSON / Excel）

任务创建只接受固定结构的文件，单条任务也用一个文件（一行 / 一个 item）。
这样「页面提交的内容」与「执行器收到的参数」只有一个来源，避免两条创建路径产生不兼容的载荷。

入口：任务管理 → 创建任务 → 分镜文件。

## 使用流程

1. 选择视频 / 图像，选择渠道与模型（一个渠道有多个模型时才需要选模型）。
2. 点「JSON 示例」或「Excel 示例」下载模板。
3. 按模板填好内容（参考图路径写在文件里，按顺序排列）。
4. 创建页的「视频前置提示词」默认取当前项目风格，可直接改；保存任务后它会拼在每一镜的视频提示词前面。
4. 上传文件：解析后是一张可编辑表格，每个分镜一行，可以直接改分镜名称、视频提示词、画幅、时长，也能删除 / 新增分镜和参考图。
5. 解析只生成预览，不会写素材库；点「保存任务」后才按任务 id 建 `assets/分镜/<任务>/`，并把镜头和参考图同步进去。
6. 确认无误后点「保存任务」；任务进入调度页的「未分配」，不会立即执行。

## Excel（.xlsx）

第一张表解析，第一行是表头。**按列名识别，顺序可以调整**；缺少「提示词」列才会报错。

| 列 | 必填 | 说明 |
| --- | --- | --- |
| 分镜名称 | 否 | 留空时用提示词开头代替；同时作为素材库分镜目录名 |
| 视频提示词 | 是 | 一段话描述画面、主体动作、镜头与光线 |
| 参考图（按顺序） | 否 | 绝对路径，或相对素材库的路径；多个用英文分号 `;` 分隔 |
| 参考图说明（按顺序） | 否 | 与参考图一一对应，说明这张图是什么（角色 / 首帧 / 场景） |
| 视频画幅 | 否 | `16:9` / `9:16` / `1:1` / `4:3` / `3:4`；留空用渠道默认值 |
| 视频时长 | 否 | 1–15 的整数；留空用渠道默认值 |
| 视频模型 | 否 | 只对管理器豆包生效：`Seedance 2.0 Mini` / `Seedance 2.0 Fast`；Gemini 留空 |

模板之外的列会原样保留；已废弃的「分辨率 / 生成张数 / 参考音频」列会被忽略。
第二张表「填写说明」只用于阅读，不参与解析。

## JSON

```json
{
  "version": 1,
  "items": [
    {
      "title": "镜头 01",
      "prompt": "雨夜的旧城街道，镜头缓慢推近。",
      "prefixPrompt": "电影感，35mm 胶片，冷色调。",
      "images": [
        { "path": "D:/素材/ref-01.png", "note": "女主正面" },
        { "path": "D:/素材/ref-02.png", "note": "女主背影" }
      ],
      "duration": 10,
      "ratio": "16:9",
      "model": "Seedance 2.0 Fast"
    }
  ]
}
```

- 顶层必须是对象，含 `items` 数组（兼容旧文件的 `tasks` 数组，会给一条提醒）。
- `images` 的 `path` 与 Excel 的参考图规则一致，数组顺序就是图一到图九；`note` 对应说明。
- `duration` / `ratio` / `model` 可省略，省略时用渠道默认值。
- `ratio` 就是发给管理器的画幅：管理器豆包认 `16:9` / `9:16` / `1:1` / `4:3` / `3:4`，Gemini 只有 `16:9` / `9:16`。
- `model` 就是发给管理器的模型名，豆包是 `Seedance 2.0 Mini` / `Seedance 2.0 Fast`（也认 `mini`、`fast`、`seedance 2.0 fast` 这类写法，会自动归一成页面上的文案）；Gemini 没有模型选项，写空或不写。
- `prefixPrompt`（视频前置提示词）可选，页面会展示在分镜资料卡里。
- 已废弃的 `resolution` / `count` / `audios` 会被忽略，不进入分镜资料。
- 常见别名也能识别：`aspectRatio` → 画幅、`model` / `模型` → 视频模型、`seconds` → 时长、`refs` → 图片、`name` / `shot` → 标题、`subject` → 说明。
- 不认识的字段原样放进 `extra`，并在页面上提示字段名；也可以在 item 里显式写 `"extra": { "景别": "中景" }`。
- 旧的 `tasks`、`aspectRatio`、`extra` 都能解析；旧的 `audios` / `resolution` / `count` 会被忽略。

## 编辑分镜时的比例、模型与参考图

任务详情 → 镜头 →「编辑分镜」里，除了提示词，还能直接改这条子任务的 **比例**、**视频模型** 和 **参考图**（这些都是要发给管理器的参数）：

- 比例下拉是 `16:9 横屏` / `9:16 竖屏`（管理器豆包还支持时会一并列出 `1:1` / `4:3` / `3:4`）；Gemini 只有前两个。
- 视频模型下拉是 `Seedance 2.0 Mini` / `Seedance 2.0 Fast`，另有「不指定（用管理器当前设置）」；Gemini 页面上没有模型选项，只显示提示不发模型。
- 参考图按 `图1`、`图2`… 的顺序排（顺序就是提示词里 `<Picture n>` 的顺序）：点缩略图放大看原图，每张都能 **替换**（选本地图片，走 `/api/upload/raw` 落盘）或 **删除**，也可以「添加图片」追加；上限取该视频模型的张数（管理器豆包 9 张）。
- 服务端会重新校验：图片必须真实存在、数量不超过模型上限，写回 `item.input.images` 与任务记录的 `images`，重试时按新顺序重新上传给管理器。
- 保存不会自动提交；点「保存并重试」才会带新参数重新生成这一条。改动只影响这一条子任务，写回 `item.input`、任务记录和生成快照。

## 任务详情自动刷新

详情页右上角有「刷新」按钮，随时重新读取这条任务的最新状态和成片；只要还有分镜在排队 / 执行，页面每 5 秒自己更新一次（正在播放的成片不打断），不用切页签。

## 校验与报错
- 解析阶段检查：提示词为空、参考图 / 音频文件是否存在、时长 / 画幅 / 张数取值、参考图不超过 9 张、音频不超过 3 段。
- 错误按行号返回（Excel 用实际行号），页面上整块列出；只要还有错误，保存按钮会拒绝提交。
- 渠道限制（例如某模型只支持 5–15 秒）在保存时校验。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/task-import/template?format=json` | 下载 JSON 模板 |
| GET | `/api/task-import/template?format=xlsx` | 下载 Excel 模板（含填写说明表） |
| POST | `/api/task-import/parse` | `{ name, data }`（`data` 为 base64），返回解析后的条目、错误与统计 |

模板由 `src/task-import.js` 生成；XLSX 的读写不依赖第三方库（ZIP + 表格 XML），可直接用 Excel / WPS / openpyxl 打开。
