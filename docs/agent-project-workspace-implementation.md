- 任意命令使用指定 Git Bash；工作区权限关闭通用命令执行，保留受路径校验的文件工具。需要执行脚本时须由用户明确选择完全权限；这不是操作系统沙箱。

## 回滚

业务代码用上述源码副本恢复本轮修改部分，不能覆盖同工作区后来新增的其他修改。

文件迁移可在停止智能体后，通过 Git Bash 在 agent_backend 下执行：

    <Python路径> -m app.workspace_migrate --report ../../output/agent-workspace-inventory.json --rollback

回滚撤销迁移位置映射，恢复旧位置读取，保留两侧实体文件。文件在迁移后发生改动或已有新版本时工具会拒绝覆盖回滚，需逐文件评估。数据库备份只供离线整体恢复，不应在产生新会话后直接覆盖。

## 保留边界

三份摘要变化的历史文件尚未自动迁移；旧目录仍保留用于兼容与回滚。全局配置、凭据和原会话数据库仍由服务管理，项目内已有会话导出和文件索引；尚未实现“仅复制项目目录到全新机器即可完整恢复所有服务状态”。

脚本工具写入和运行收尾扫描可发现文件，但任意外部程序对项目资产的修改尚无实时文件监听与自动历史版本。项目级 index 同步失败会作为登记错误暴露，未建立跨文件系统和两个 SQLite 数据库的分布式事务。
