# RunningHub H3 插件接入验收（国内站 + 国际站）

日期：2026-10-31。范围：按 `docs/runninghub-h3-cn-ai-api-reference.md` 与同名 JSON 重建 `Creation-Studio/plugins/video/runninghub-h3`，并做回归与真实数据核对。未提交任何真实付费生成。

## 变更

- `workflows.json` 改为「站点 + 应用」结构：国内站 6 个、国际站 4 个，逐个应用保存提示词节点、时长节点、比例节点、9 个参考图节点的公开顺序与默认值，来源标记为文档。

- `src/workflows.js` 补 `runninghub` 的中文 provider 名称与提示，界面不再显示小写 `[runninghub]`。
- `web/app.js` 画幅下拉改用工作流自带的 `ratios`，RunningHub 可正常选择文档里的 8 种画幅。

## 与旧映射的差异

## 未覆盖

- 时长枚举：文档记录平台默认 15 秒但未给出业务上下限，界面仍按 1–15 秒开放；实际平台可接受区间未核实。
- 取消：平台未提供取消接口，插件不声明 `cancel`；本地停止只终止轮询，撤回请在平台侧操作。
- 国际站真实生成未执行（缺少国际站密钥的实际提交意愿）；国际站仅通过公开详情核对与本地 mock 提交验证。

## 追加：多账号密钥池（1.3.0，2026-10-31）

- `API Key` 改为多行（每行一个账号），新增可选「账号名」字段（每行一个，顺序对应）。
- 每个账号派生一个调度槽，`每个账号并发` 默认 1；总并发 = 账号数 × 该值，仍受全局并发上限约束（当前 10）。
- 任务绑定账号：提交记下序号，轮询 / 继续原任务 / 重试都用同一把 Key；`params.json` 落 `accountIndex` 与账号名。
- 密钥失效的账号在渠道测试里单独列出（不回显密钥）；`clearKey` 显式清空，留空保存仍保留原密钥。
