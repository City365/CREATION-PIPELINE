# 01 · 快速开始

目标：从零到第一个能在剪映里打开、带 BGM 的草稿。

全程命令行，不需要打开剪映界面。

---

## 0. 前提

- 剪映专业版已安装（本文按 11.5.0.14471，路径 `D:\notebook\software\JianyingPro\11.5.0.14471`）
- `.venv-jianying` 已存在（在 `CREATION-PIPELINE` 根目录）
- 没有就装：

```powershell

python -m venv .venv-jianying
uv pip install --python .venv-jianying\Scripts\python.exe pyJianYingDraft==0.3.0 capstone==5.0.9
```

自检：

```powershell
cd JianYing-Automatic-editing
powershell -ExecutionPolicy Bypass -File env\setup.ps1
```

## 1. 搜一首 BGM

```powershell
cd src

```

输出：

    "author": "Mr.music",

## 2. 下到本地

```powershell
..\..\.venv-jianying\Scripts\python.exe lyra.py download music 7100504520542668814 ..\output\bgm
```

输出里的 `path` 就是要用的音频文件（m4a / AAC 44.1 kHz）。

> 不传目录会落到 `output\jy-library\downloads`。

## 3. 建草稿

```powershell
$py = '..\..\.venv-jianying\Scripts\python.exe'
& $py -c "
import sys; sys.path.insert(0,'.')
import server as api, json
print(json.dumps(api.ep_create_draft({'name':'我的第一个草稿','width':1080,'height':1920,'fps':30}), ensure_ascii=False))
"
```

---

## 4. 加片段

```powershell
& $py -c "
import sys; sys.path.insert(0,'.')
import server as api, json
n='我的第一个草稿'
print(json.dumps(api.ep_add_video(n, {'path': r'D:\素材\a.mp4', 'duration': 3}), ensure_ascii=False))
print(json.dumps(api.ep_add_video(n, {'path': r'D:\素材\b.mp4', 'duration': 3}), ensure_ascii=False))
"
```

`duration` 是放到时间线上的长度（会自动裁切），`in` 是源素材入点（秒）。

---

## 5. 加 BGM

```powershell
& $py -c "
import sys; sys.path.insert(0,'.')
import server as api, json
print(json.dumps(api.ep_add_audio('我的第一个草稿', {
    'path': r'D:\...\温柔治愈钢琴曲_7100504520542668814.m4a',
    'volume': 0.6, 'fade_in': 1.2, 'fade_out': 1.5
}), ensure_ascii=False))
"
```

`volume` 0~1，`fade_in` / `fade_out` 单位秒。

---

## 6. 加文字

```powershell
& $py -c "
import sys; sys.path.insert(0,'.')
import server as api, json
print(json.dumps(api.ep_add_text('我的第一个草稿', {
    'text': '她等了 99 天', 'start': 0.4, 'end': 3.0,
    'size': 80, 'color': 'white', 'y': 0.0
}), ensure_ascii=False))
"
```

注意 `y` 是 **float**（归一化坐标，`0` 居中，正数向下），不是百分比字符串。

## 7. 加转场 / 特效 / 滤镜

print(json.dumps(r.get('capabilities', r), ensure_ascii=False)[:800])

## 常见疑问

**Q：必须装剪映吗？**
写草稿阶段不需要（纯 JSON 操作），但要**在剪映里看/导出**就必须有。搜素材也依赖剪映自带的 `lyra-cli.exe`。

**Q：草稿加密吗？**
新版本剪映会加密自己生成的草稿（形如 `hFHc6dlGEHDTFtC5…` 的内容）。我们生成的是**明文 JSON**，剪映能正常打开。`jydll.py` 是用来**读**加密草稿的。

**Q：能不能不部署，直接出 mp4？**
可以，但那是 FFmpeg 路线（`..\tools\ffmpeg-timeline\edit.py`）。剪映路线要出片需要 `jy-draftc.exe`，或者部署后人工点导出。

**Q：一次能加多少个片段？**
没有硬限制，几十个正常。注意主轨片段是**首尾相接**的，`start` 由 `cursor` 自动推。
