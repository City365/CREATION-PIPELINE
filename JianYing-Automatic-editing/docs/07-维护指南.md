## 1. 剪映升级后补丁失效

### 症状

```powershell
cd src
..\..\.venv-jianying\Scripts\python.exe lyra.py search music "test" 1
# LyraError: 在 lyra-cli.exe 里没找到授权校验特征码，剪映版本可能已变更
```

或者 `music_search` 返回 `source: "cache"` 加 `native_error`。

### 原因

补丁靠特征码定位：

```text
PREFIX = 74 1C 44 38 75          # je +0x1C / cmp byte [rbp-0x5F], r14b
TAIL   = 75 16 B9 51 79 FE FF E8 # jne +0x16 / mov ecx, -100015 / call
```

编译器换版本后，寄存器分配、栈偏移、跳转距离都可能变，特征码就失配。

### 修复流程（约 15 分钟）

#### 步骤 1 · 确认错误码还在

```powershell
& "D:\notebook\software\JianyingPro\<新版>\lyra-cli.exe" --help
# {"err_code":-100015,"err_msg":"unauthorized host process",...}
```

如果错误码变了（不是 `-100015`），说明逻辑重写了，跳到「步骤 6」。

#### 步骤 2 · 找字符串

```powershell
cd re
..\..\..\.venv-jianying\Scripts\python.exe -c "
import struct
p = r'D:\notebook\software\JianyingPro\<新版>\lyra-cli.exe'
d = open(p,'rb').read()
pe = struct.unpack_from('<I',d,0x3C)[0]
n  = struct.unpack_from('<H',d,pe+6)[0]
optsz = struct.unpack_from('<H',d,pe+20)[0]
so = pe+24+optsz
secs=[]
for i in range(n):
    o=so+i*40
    vs,va,rs,ra=struct.unpack_from('<IIII',d,o+8)
    secs.append((va,vs,ra,rs))
def o2r(off):
    for va,vs,ra,rs in secs:
        if ra<=off<ra+rs: return va+(off-ra)
    return None
i = d.find(b'unauthorized host process')
print('file=0x%X rva=0x%X' % (i, o2r(i)))
"
```

记下 RVA。

#### 步骤 3 · 找 RIP-relative 引用

```powershell
..\..\..\.venv-jianying\Scripts\python.exe find_lea.py "<新版 lyra-cli.exe>" <上一步的 RVA>
```

输出类似：

```text
hit at file=0x8677B4 rva=0x8683B4 sec=.text  bytes=488d054dae1d00
```

#### 步骤 4 · 反汇编看判定

```powershell
..\..\..\.venv-jianying\Scripts\python.exe disasm_range.py "<新版 lyra-cli.exe>" <RVA-0x100> <RVA+0x80>
```

找形如：

```asm
cmp  byte [rbp-0xNN], r14b
je   <target>
cmp  byte [rbp-0xMM], r14b
jne  <target>
mov  ecx, 0xFFFE7951
call <raise>
```

#### 步骤 5 · 重新生成特征码并改代码

拿到 `jne` 的机器码（一般是 `75 <rel8>`），把它替换成 `EB <rel8>`。

把新的 PREFIX/TAIL 写进 `src/lyra.py`：

```python
PREFIX = bytes.fromhex("741c443875")
TAIL   = bytes.fromhex("7516b95179feffe8")
PATCH_OFFSET_IN_SIG = 6
```

验证：

```powershell
cd ..\src
..\..\.venv-jianying\Scripts\python.exe lyra.py patch   # force 重建
..\..\.venv-jianying\Scripts\python.exe lyra.py search music "test" 1
```

#### 步骤 6 · 如果错误码变了

说明校验逻辑重写。需要：

1. 找新错误字符串 → 同样方式找引用
2. 反汇编看判定
3. 判断能不能只改一个跳转；如果是返回值判断，找 `test al,al` / `cmp eax,0` 附近
4. 实在不行，退回到「只读本地缓存」模式（`build_music_index.py`）

**保险做法**：改前先备份 `lyra-cli.exe` 原文件。

## 2. 加一个新的 MCP 工具

### 步骤 1 · 在 `src/server.py` 写端点

```python
def ep_my_feature(name, body):
    script = _get(name)                     # 拿会话
    # ... 操作
    return {"ok": True, ...}
```

在 `ROUTES` 里注册（HTTP 用）：

```python
ROUTES[("POST", "/drafts/<n>/my-feature")] = ...
```

### 步骤 2 · 在 `src/mcp_server.py` 加工具定义

`TOOLS` 列表里加：

```python
{
    "name": "my_feature",
    "description": "一句话说清干什么、什么时候用、返回什么",
    "inputSchema": {
        "type": "object",
        "properties": {
            "draft": _p("草稿名", type="string"),
            "param": _p("参数说明", type="string"),
        },
        "required": ["draft"],
    },
},
```

### 步骤 3 · 在 `dispatch` 加分支

```python
if name == "my_feature":
    return api.ep_my_feature(args.pop("draft"), args)
```

注意：**带 `draft` 参数的工具走 `table` 分发，不带的单独 `if` 分支。**

### 步骤 4 · 验证

```powershell
$env:PYTHONIOENCODING='utf-8'
echo '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' | ..\..\.venv-jianying\Scripts\python.exe mcp_server.py
```

工具数 +1。

## 5. 已知未完成 / 可扩展

### 5.1 语音识别字幕（优先级最高）

`lyra-cli` 自带：

```powershell
lyra-cli-patched.exe media asr --input speech.m4a --language auto
lyra-cli-patched.exe draft algo subtitle-recognize --language zh
```

**接入方式**：在 `server.py` 加 `ep_asr(name, body)` → 调 `lyra.run([...])` → 把识别结果拆成多条 `text_add`。

这是剪辑里最费人工的环节，接上后价值很大。

### 5.2 draft 域的其他能力

```powershell
lyra-cli-patched.exe draft --help
```

支持 `project create` / `video add` / `blueprint apply` / `cover set`。

`blueprint apply` 可能能用剪映的模板系统，比自己拼轨道效率高。

### 5.3 material topic / recommend / similar

```powershell
lyra-cli-patched.exe material topic --type music
lyra-cli-patched.exe material recommend --type sticker --limit 10
lyra-cli-patched.exe material similar --type music --resource-id <ID>
```

`topic` 是"逛专题"，比 `search` 更适合"不知道要什么、先看看有啥"的场景。

### 5.4 无头导出

装 `jy-draftc.exe` 到 `bin/`，`export` 就能全自动。

### 5.5 已知缺陷

| 项 | 说明 |
|---|---|
| 部署权限 | Python subprocess 写不进草稿目录，需要原生 PowerShell |
| 补丁版本绑定 | 剪映大版本更新需重新逆向 |
| 缓存索引字段 | `build_music_index.py` 生成的 `music_index.json` 顶层是 `items` 不是数组，读取时注意 |
| 素材付费 | `paid_mode: subscribe` 能搜能下（试听版），正式使用带不带水印取决于账号 VIP |
