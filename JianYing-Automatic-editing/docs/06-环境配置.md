## 3. 环境变量

全部可选，不设也能跑（有自动探测）。

| 变量 | 作用 | 默认 |
|---|---|---|
| `JIANYING_HOME` | 剪映安装根目录 | 依次探测 `Program Files` / `D:\notebook\software\JianyingPro` / `%LOCALAPPDATA%`，取版本号最大的子目录 |
| `JY_DRAFTC_EXE` | `jy-draftc.exe` 路径（无头导出） | 探测 `bin\jy-draftc.exe` |
| `PYTHONIOENCODING` | 建议设为 `utf-8` | — |

## 4. 从零搭建

### 4.1 装剪映

装 **11.5.0.14471**（或更新的 11.x）。装完确认：

```powershell
Test-Path 'D:\notebook\software\JianyingPro\11.5.0.14471\lyra-cli.exe'
```

### 4.2 建虚拟环境

```powershell
cd D:\notebook\AIGC\CREATION-PIPELINE
python -m venv .venv-jianying
```

### 4.3 装依赖

用 `uv`（推荐，venv 里没 pip 也能装）：

```powershell
uv pip install --python .venv-jianying\Scripts\python.exe pyJianYingDraft==0.3.0 capstone==5.0.9
```

或者：

```powershell
.venv-jianying\Scripts\python.exe -m ensurepip --upgrade
.venv-jianying\Scripts\python.exe -m pip install -r env\requirements.txt
```

> 注意：这个 venv 默认**没有 pip**，`python -m pip` 会报 `No module named pip`。这是 `uv` 建的 venv 的正常状态。

### 4.4 自检

```powershell
cd JianYing-Automatic-editing
powershell -ExecutionPolicy Bypass -File env\setup.ps1
```

## 5. 换机器

### 5.1 必须重新做的

| 项 | 为什么 |
|---|---|
| **重新生成 lyra 补丁** | 补丁绑定剪映 exe 的字节，换安装即失效。`lyra.py` 会自动重新找特征码并打补丁，一般无需手动干预 |
| **重新登剪映** | cookie 是 DPAPI 加密的，绑定 Windows 用户账户 |
| **改硬编码路径** | `server.py` 里 `JY_DRAFT_ROOT = r"D:\notebook\software\JianyingPro Drafts"` 要改成目标机路径 |

### 5.2 可以直接搬的

`src/` `re/` `docs/` `env/` 全部可搬。代码里没有绝对路径硬编码（`JY_DRAFT_ROOT` 除外）。

### 5.3 剪映版本不同时的风险

| 情况 | 后果 | 处理 |
|---|---|---|
| 小版本更新（11.5.0.x → 11.5.1.x） | 特征码大概率仍然匹配 | 自动 |
| 中版本更新（11.5 → 11.6） | 可能失配 | 见 `07-维护指南.md` |
| 大版本更新（11.x → 12.x） | 需要重新逆向 | 见 `07-维护指南.md` |

## 6. 可选组件

### 6.1 jy-draftc（无头导出）

第三方基于剪映引擎的渲染器，能不开界面直接出 mp4。

放法：

```text
JianYing-Automatic-editing\bin\jy-draftc.exe
```

或设环境变量：

```powershell
$env:JY_DRAFTC_EXE = 'D:\tools\jy-draftc.exe'
```

没有它 `export` 会返回 `mode: "deployed_only"`，草稿进列表、需要人工点导出。

### 6.2 ffmpeg（FFmpeg 路线）

```text
D:\notebook\software\ffmpeg\bin\ffmpeg.exe
```

只在跑 `tools/ffmpeg-timeline/edit.py` 时需要。剪映草稿路线**不需要** ffmpeg。

## 8. 权限说明

| 操作 | 需要的权限 |
|---|---|
| 读剪映安装目录 | 普通用户 |
| **写剪映安装目录**（补丁） | 普通用户（实测可写 `lyra-cli-patched.exe`），某些配置需管理员 |
| 写草稿根目录 | 普通用户 |
| 写 `%LOCALAPPDATA%\JianyingPro` | 普通用户 |
| 用真剪映进程当父进程 | **管理员**（`PROCESS_CREATE_PROCESS`）——本方案不需要 |

**已知限制**：从 Python subprocess 里拉起的 PowerShell 会继承受限 token，写不进剪映目录（见 `05-问题排查日志.md` P05/P12）。原生 PowerShell 没这个问题。
