# lyra-cli 原生通道：授权绕过 + 完整命令表

> 剪映 11.5.0.14471 · lyra-cli version `dev-dd61f478`
> 本文记录如何让脚本直接驱动剪映原生素材平台和媒体处理能力。

---

## 1. 问题：`-100015 unauthorized host process`

`lyra-cli.exe` 是剪映内置的官方命令行工具，能搜素材、下素材、改草稿、跑语音识别。
但它启动时先做一次宿主校验，不是剪映主程序拉起来的就直接拒绝：

```json
{"err_category":"runtime","err_code":-100015,"err_msg":"unauthorized host process",
 "recovery":"upgrade_or_switch_path","result":null,"severity":"failed"}
```

连 `--help` 都拒绝，`exit=1`。

### 走过的弯路

| 尝试 | 结果 |
|---|---|
| 直接跑 | `-100015` |
| `--parent explorer/cmd` | `-100015` |
| 伪装父进程为 `JianyingPro.exe`（复制 python.exe 改名） | `exit=0` 但**零网络、零管道、零输出** —— 其实是被骗后静默退出，不是真的通过 |
| 用 `jianying-agent-cli.exe` 当父进程 | 同类问题，且它的白名单只放 `edit` / `extract` |

Procmon 抓包证明了父进程伪装是假突破：那次运行只有 16 次文件属性读取，没有任何实际动作。

---

## 2. 真正的定位路径

### 2.1 从错误字符串找到判定点

```text
"unauthorized host process"
  lyra-cli.exe        RVA 0x00A43208   (.rdata)
  lyra_cli_client.dll RVA 0x0078E9C8   (.rdata)
```

只搜 `lea` 找不到引用，因为编译器用的是 **RIP-relative 编码**，需要按 `REX + 8D + modrm` 机器码模式扫描并回算目标地址：

```asm
48 8D 05 <disp32>     lea rax, [rip + disp]      ; disp = target - (rva + 7)
```

结果：各有 **1 处**真实引用。

### 2.2 判定逻辑

`lyra-cli.exe` RVA `0x1A3A8` 附近：

```asm
0x1A392   lea  rcx, [rbp-0x60]
0x1A396   call 0x140885310            ; 填两个 bool: [rbp-0x60], [rbp-0x5F]
0x1A39C   cmp  byte [rbp-0x60], r14b  ; flag A == 0 ?
0x1A3A0   je   0x1A3BE                ; A==0  → 放行
0x1A3A2   cmp  byte [rbp-0x5F], r14b  ; flag B == 0 ?
0x1A3A6   jne  0x1A3BE                ; B!=0  → 放行
0x1A3A8   mov  ecx, 0xFFFE7951        ; -100015
0x1A3AD   call 0x140925360            ; 抛错
```

`0x140885310` 会调 `[IAT 0x9A51F0]`（进程快照类 API）遍历进程做宿主比对。

**判据：flag A != 0 且 flag B == 0 时报错。** 把 `jne` 变成无条件跳转即可放行。

### 2.3 补丁

文件偏移 `0x197A6`：

```text
before: 74 1C 44 38 75 A1 75 16 B9 51 79 FE FF
                        ^^
after : 74 1C 44 38 75 A1 EB 16 B9 51 79 FE FF
```

一个字节：`0x75 (jne)` → `0xEB (jmp)`。

### 2.4 自动化重建

`src/lyra.py` 用特征码定位，剪映升级后会自动重新找：

```text
PREFIX = 74 1C 44 38 75          # je / cmp [rbp-0x5F], r14b
TAIL   = 75 16 B9 51 79 FE FF E8 # jne / mov ecx,-100015 / call
patch offset = PREFIX 命中位置 + 6
```

找不到就抛 `LyraError`，不会静默改错字节。

安装目录不可写时（Windows ACL），补丁副本落在 `output/_lyra/lyra-cli-patched.exe`，运行时把安装目录塞进 `PATH` 让 DLL 能被找到。

```powershell
# 生成/刷新补丁
.\.venv-jianying\Scripts\python.exe src\lyra.py
# 强制重建
.\.venv-jianying\Scripts\python.exe src\lyra.py patch
```

## 3. 完整命令结构

```text
lyra-cli <domain> <[subdomain] ...> <action> [--flags] [--options]
```

### 3.1 域列表

| 域 | 能力 |
|---|---|
| `draft` | 草稿工程：项目创建、轨道增删、素材绑定、蓝图应用、算法（字幕识别等） |
| `material` | 素材平台：搜索、下载、查询、专题、推荐、相似、MotionGraph |
| `media` | 本地媒体处理 + AIGC：压缩、裁切、截帧、**ASR 语音识别** |
| `auth` | 账号登录（`auth login` / `auth qrcode`） |
| `lint` | 命令契约校验 |
| `upgrade` | 自升级 |

### 3.2 素材搜索（核心）

```powershell
lyra-cli-patched.exe material search --type music --prompt "温暖 钢琴 治愈" --limit 5
lyra-cli-patched.exe material search --type sticker --prompt "cute cat" --limit 5
lyra-cli-patched.exe material search --type effect --prompt "film grain" --filter-commercial
lyra-cli-patched.exe material search --type anim_text --prompt "fade in" --category-list 2066 --search-scene vimo_caption
```

参数：

| 参数 | 说明 |
|---|---|
| `--type` | 素材类型（见下表），**必填** |
| `--prompt` | 搜索意图：物体 / 情绪 / 场景 / 风格 / 乐器 / 节奏 / 声音机制，**必填** |
| `--limit` | 返回条数，默认 10 |
| `--need-recommend` | 开启推荐增强排序 |
| `--filter-commercial` | 只返回可商用素材 |
| `--search-scene` | 搜索场景，如 `vimo_caption` |
| `--category-list` | 逗号分隔的分类 ID，如 `2066,2067` |
| `--channel` | `online` / `test` / `local_test` |
| `--jq` | JSON 选择器，如 `.result.items[0].id` |

**支持的 34 种素材类型：**

```text
template  music  sticker  effect  filter  transition  text_template  sound
font  flower  subtitle_template  photo  video  material_package  emoji_sticker
lyric_animation  anim_text  anim_sticker  anim_video  curve_speed
digital_human_template  digital_human_background  digital_human_model
face_effect  face_sticker  auto_face  auto_makeup  matting_stroke
mix_mode  material_lib  style  tone  video_mask  voice_change
```

返回：

```json
{
  "resource_id": "7491905758919362623",
  "title": "温柔钢琴 舒缓叙事 你的倒影",
  "author": "废铁",
  "duration": 161,
  "paid_mode": "subscribe",
  "is_commerce": true,
  "preview_url": "https://...mime_type=audio_mp4...",
  "cover_url": {"hd": "...", "large": "...", "medium": "...", "thumb": "..."}
}
```

### 3.3 素材下载

```powershell
lyra-cli-patched.exe material download --type music --resource-id 7419214980241213455 `
  --resource-platform music --resource-dir D:\path\to\out
```

| 参数 | 说明 |
|---|---|
| `--type` / `--resource-id` | 必填 |
| `--resource-platform` | `vimo` / `heycan` / `loki`（视觉、音频类）/ `music`（音乐）；数字 `1` `2` `3` 兼容 |
| `--resource-dir` | 目标目录；省略则用平台默认素材缓存 |

音乐下载的是 **试听音频**（m4a / AAC 44.1 kHz）；视觉音频素材下载的是素材包。

实测：免费曲目、VIP 曲目都能下。

```powershell
lyra-cli-patched.exe media trim-video --input in.mp4 --output clip.mp4 --start 1s --end 5s

```

### 3.6 草稿工程

```powershell
lyra-cli-patched.exe draft project create --ref local://example
lyra-cli-patched.exe draft video add --resource local:///x/y.mp4
lyra-cli-patched.exe draft algo subtitle-recognize --language zh
```

## 4. Python 接口

`src/lyra.py`：

```python
import lyra

# 搜索
res = lyra.search("music", "温暖 钢琴 治愈", limit=5)
items = lyra.simplify(res["items"])

# 下载
out = lyra.download("music", items[0]["resource_id"], r"D:\bgm")
print(out["path"])          # D:\bgm\温柔钢琴_...m4a

# 任意命令
lyra.run(["material", "topic", "--type", "music"])
```

命令行：

```powershell
python lyra.py                                    # 打印安装目录 + 补丁状态
python lyra.py search music "治愈钢琴" 5
python lyra.py download music <resource_id> <dir>
python lyra.py raw draft --help
python lyra.py patch                              # 强制重建补丁
```

### MCP 工具

| 工具 | 调用 |
|---|---|
| `music_search` | `lyra.search(type, keyword, limit)` |
| `music_download` | `lyra.download("music", resource_id)` |
| `material_search` | `lyra.search(type, prompt, limit, filter_commercial=...)` |
| `material_download` | `lyra.download(type, resource_id)` |

`music_search` 在原生通道不可用时自动回退本地缓存索引（`output/jy-library/music_index.json`），返回值里 `source` 字段标明 `native` 还是 `cache`。

## 6. 已知限制

1. **补丁是版本相关的。** 剪映升级后 `lyra-cli.exe` 会变，特征码可能失配 → `lyra.py` 抛错。此时按 §2 重新定位（字符串 → RIP-relative lea → 反汇编 → 改 `jne`）。
2. **网络是必需的。** 素材搜索/下载走 `lv-api.ulikecam.com` 等域，离线时只能回退本地缓存索引。
3. **付费判定在服务端。** `paid_mode: "subscribe"` 的曲子能搜能下（试听版），但正式使用是否带水印由剪映导出环节决定，取决于账号 VIP 状态。
4. **`--resource-dir` 是必须关注的。** 不传会用平台默认缓存目录，容易把下载的素材混进剪映自身缓存。
5. **`-100015` 只在 exe 入口检查。** `lyra_cli_client.dll` 里没有这段逻辑，理论上也可以直接 `LoadLibrary` + 调 `lyra_cli::Client::Create` 绕过，但导出只有 14 个符号（ctor / dtor / copy / `Create` / `RegisterTelemetryReporter`），`CreateOptions` 结构未逆向，所以走 exe 补丁更省事。
